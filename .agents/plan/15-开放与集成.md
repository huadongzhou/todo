## 技术要点

- 邮件转任务：需入站邮件通道（收件域名 + 入站解析服务），为本方案唯一新增外部基础设施，选型与成本第一个子任务定案；地址含用户随机片段，防猜测。
- 开放 API：在 `/v1` 下开 `api/` 命名空间，鉴权用独立 API Token（与登录 token 分离、可吊销、按 5.3 限流）；Webhook 出站带签名头，失败重试有上限；OpenAPI 描述文件随 contracts 生成链路输出。
- URI 深链：Windows 协议注册（安装包写注册表）+ 单实例路由（复用 8.4 单实例通道把深链转发给已运行实例）；路由表与 9.3 小组件 deep link 同一份。
- 网页分享：服务端渲染只读页（无需登录访问），链接为不可枚举随机 id，可主动失效；页面同时是拉新落地页（带下载引导，文案随方案 12 运营段）。
