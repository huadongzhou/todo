## 技术要点

- 视图端平台无关是前提（AGENTS.md），移动端复用同一 Vue 应用，导航壳按平台探测（`src/lib/` 既有探测）切换布局；触控目标与 safe-area 按 DESIGN.md 基准。
- 小组件是原生层开发（Swift WidgetKit / Kotlin AppWidget），数据经共享存储（App Group / SharedPreferences）由 Rust 侧写入，deep link 复用 15.3 todo:// 路由。
- 语音输入用系统听写（iOS Dictation / Android SpeechRecognizer），不自建模型；share sheet 为系统扩展注册。
- 风险：Tauri 2 移动端小组件与扩展生态尚新，9.3/9.5 各含一次可行性验证；iOS 构建与上架依赖 macOS 环境与开发者账号（列为环境前置，非代码任务）。
