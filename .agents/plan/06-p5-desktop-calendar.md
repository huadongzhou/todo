## 技术方案

- **窗口演进**：复用今日卡片窗口机制（`index.html?card=today` 分流、DPI 定位、event 双向同步），新增 `?card=calendar` 形态或直接升级现有卡片——布局为 月历（`CalendarMonth` 复用）+ 统计条（`stats.ts` 复用）+ 当日/周/月任务速览三段；卡片内点击任务唤起主窗并定位（现有 event 通道扩展 `focus-todo` 消息）。
- **常驻层级**：现有置顶（always-on-top）为第一形态；「嵌入桌面层级」（贴桌面、不随 Alt+Tab）依赖平台特定 API，列为分平台调研任务——Windows 优先（SetParent/WorkerW 方案调研），macOS/Linux 视调研结论决定是否降级为置顶模式并在 README 矩阵注明。
- **开机自启**：`tauri-plugin-autostart`（新依赖，理由：官方插件覆盖三平台注册表/LaunchAgent/autostart 规范），设置面板加开关，默认关。
- **单实例**：`tauri-plugin-single-instance`（README 挂起项）；二次启动唤起既有主窗。
- **设置联动**：卡片显示开关沿用现有 `showTodayCard`，更名语义为「桌面月历表」；文案与可访问性按 DESIGN.md。

## 验收标准

1. 月历表窗口展示月视图、统计与三档任务速览，数据与主窗实时一致。
2. 点击月历表内任务，主窗唤起并定位该任务。
3. 开机自启开关生效（Windows 实测）；重复启动不产生第二实例。
4. DPI 缩放与多显示器定位正确（沿用现有卡片判据）。

## 验证方式

`tauri:dev` 双窗口手测同步与定位；打包 `tauri:build` 实测自启与单实例；`pnpm run check`。
