## 技术要点

- 契约/领域：`Todo` 实体扩展字段已列于 TODO 6.2 契约扩展；周期规则计算（下一实例、跨月末、工作日/农历换算）全部落 `crates/domain/`（纯规则、可单测），农历与节假日数据源在 Rust 侧内置数据表（节假日调休需年度更新机制，作为已知维护项）。
- 客户端：新增 command 经 `#[tauri::command]` + `#[specta::specta]` 注册，`pnpm run types:generate` 后前端经 `nativeCommands` 消费；实例生成在完成/到期事件时由 Rust 侧执行，避免前端时钟不可靠。
- 视图端：创建界面重构 `App.vue` 详情展开区为完整设置面板（组件拆分进 `src/components/`）；撤销/重做在 Pinia store 实现操作栈（命令模式，深度上限设常量）；归档/顺延为启动时 + 日切时的批处理。
- 风险：任务依赖的环检测须在 domain 层校验；撤销栈与同步操作日志（op-based）的关系需在设计阶段明确（撤销=生成逆操作，不回滚日志）。
