# P0 · 视图与统计

不动数据层，纯视图端工作。打通「回顾」环，并为 P5 桌面月历表产出可复用组件。

## 范围（TODO 映射）

- 模块 8：主窗口「任务 / 视图」两段导航
- 模块 7：任务统计（当日/周/月数与完成率）、月历视图
- 模块 1.1：编辑入口补全（store 已支持，缺 UI）

不含：四象限 tab（P3）、回顾页（设想，暂缓）。

## 技术方案

- **导航**：不引入 vue-router；`App.vue` 以视图态切换「任务 / 视图」两段（现有 `isCard` 分流模式的延伸），保持单页应用形态。视图页内部再分「月历 / 统计」区块（四象限 tab 位留待 P3）。
- **统计计算**：纯函数落 `src/lib/stats.ts`——输入 `Todo[]` 与基准日，输出当日/本周/本月的任务数、完成数、完成率；周起始日暂定周一（后续入设置，TODO 模块 10 设想项）。今日卡片与 P5 月历表复用同一函数。
- **月历组件**：`src/components/CalendarMonth.vue`——月网格、按日任务数/完成标记、月份切换、点击日期展开当日任务清单；样式全部走 DESIGN.md 令牌（slate 网格线、brand 高亮当日、三档语义色标记逾期）。
- **编辑入口**：待办行进入编辑态（标题/截止日/提醒时刻），复用创建表单的控件；调用现有 `todoStore.update`。

## 验收标准

1. 主窗口可在「任务 / 视图」间切换，默认任务页，状态不丢失。
2. 视图页显示当日/本周/本月任务数与完成率，随任务变更即时刷新。
3. 月历按日标记任务分布与完成情况，可切换月份、点击日期查看当日任务。
4. 任意待办可编辑标题/截止日/提醒并生效（含同步操作记录）。
5. 浅色/暗色两种模式对比达标，全流程键盘可操作。

## 验证方式

`pnpm run check` 通过；`pnpm run dev` 与 `pnpm run tauri:dev` 手动走查上述验收项（AGENTS 当前阶段验证标准）。

## 风险与依赖

- 无数据层依赖；统计函数需明确定义「本周」边界（暂定周一起始，写入函数注释与本文件）。
- 月历性能：单月任务量级小，无虚拟化需求；若日清单过长做内部滚动。
