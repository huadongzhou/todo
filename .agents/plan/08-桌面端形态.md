## 技术要点

- 月历表窗口：在现有今日卡片窗口（DPI 感知、event 双向同步）基础上扩容，复用 07 的月视图与统计组件（视图端平台无关，经窗口路由加载）；卡片交互（勾选/快添）走既有 event 通道回主 store。
- 常驻：嵌入桌面层级在 Windows 上为 bottom-most 窗口层级设置（Tauri window API + Win32 调用），失败按 AGENTS.md 容错降级为普通置顶窗口并 `log::warn!`。
- 单实例：`tauri-plugin-single-instance` 依赖就绪情况在子任务内先验证（TODO 备注其曾不可用），不可用则 Rust 侧自实现（命名互斥量）。
- Windows 集成：角标用任务栏 overlay icon；跳转列表用 Windows JumpList API；Win11 小组件需 Widget Provider（COM/包身份），先做一个可行性评估子任务，结论不可行则该点降级为「远期」并报编排者（全局规则 5）。
- 键盘体系：快捷键表集中定义（供 10.2 设置面板与 12.8 速查表共用一份数据源）。
