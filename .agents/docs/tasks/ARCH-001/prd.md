# PRD：Tauri 2 跨端基础架构

## 目标

建立可复用的跨端待办应用工程，开发者可在浏览器调试并通过 Tauri 2 打包到桌面和移动端。

## 非目标

本任务不实现持久化、账号、同步、提醒、分类、云端 API 或任一生产发布。

## 用户故事与验收

1. 用户可以新增一条非空待办；提交空白内容不创建项目。
2. 用户可以将待办标记为完成或恢复为未完成，并可以删除待办。
3. 开发者可以使用统一命令运行类型检查、前端构建和 Tauri 桌面开发。
4. 维护者可以从仓库文档了解模块边界、目录、流程和平台限制。

## 边界

- 窄屏最小宽度为 320px；交互控件有可访问名称且可键盘聚焦。
- 示范数据只存于运行时内存，刷新或重启后清空是预期行为。
- 持久化、同步和发布身份由后续任务和人工决策定义。
