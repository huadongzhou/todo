# 设计：最小待办基线

## 信息架构与流程

单页包含页头（名称及未完成数量）、新增表单与待办列表。输入标题后点击“添加”或回车，条目出现在顶部；用户可切换完成状态或删除。无项目时显示空状态。

## 状态与无障碍

| 区域 | 默认 | 禁用 / 空 | 无障碍 |
| --- | --- | --- | --- |
| 新增表单 | 输入框和添加按钮 | 空白输入时按钮禁用 | 输入框与按钮均有名称 |
| 待办条目 | 标题、完成切换、删除 | 已完成标题删除线 | 状态和删除动作为具名按钮 |
| 列表 | 逐项显示 | 无条目时空状态 | 标题层级与列表区域标签 |

## 响应式与视觉

320px 起单栏，内容最大宽度 672px；使用浅灰背景、白色卡片、天蓝色主操作和清晰焦点环。不可仅通过颜色区分状态。
