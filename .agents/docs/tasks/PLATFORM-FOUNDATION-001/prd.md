# 平台基础层：设置、主题与诊断日志

## 目标

为跨端待办建立首个可复用的平台层：用户能选择并保存主题，应用能在桌面端记录可诊断日志；网页开发环境保持可运行。

## 非目标

- 托盘、开机启动、全局快捷键、桌面卡片和提醒调度。
- 任务持久化、同步、账号或生产日志上报。
- 设置分类导航与完整设置中心。

## 用户故事与验收

1. 用户可从主界面打开设置并选择浅色、深色或跟随系统主题；选择后界面立即更新。
2. 用户重启桌面应用后，之前选择的主题仍会恢复。
3. 开发者可在浏览器运行前端；此时主题仍会保存，日志不会因原生插件不存在而报错。
4. 发生设置读写失败时，应用使用安全默认值且记录不包含任务正文或敏感信息的诊断日志。

## 边界与度量

- 仅保存 `appearance.theme`；偏好文件不承载待办数据。
- 所有 UI 控件可通过键盘操作并有可访问名称。
- 验证以 `pnpm run check`、Rust 类型绑定测试和人工主题切换为准。
