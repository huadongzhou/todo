# 设置与主题设计规格

## 信息架构与主流程

- 主界面标题栏右侧提供“设置”图标按钮。
- 设置作为主内容下方的可关闭面板，首期仅包含“外观”分组。
- 用户选择主题单选项后立刻获得视觉反馈；保存在后台完成，不阻塞选择。

## 组件与状态

- `Settings` 图标按钮：有 `aria-label`，焦点可见。
- 外观卡片：包含说明文本和三个原生单选控件（浅色、深色、跟随系统）。
- 加载：首次恢复偏好前显示“正在恢复设置”。
- 错误：读写失败时不阻断使用，保留安全默认主题，并显示简短状态文本。

## 响应式与无障碍

- 小屏幕上标题栏允许换行；主题选项垂直排列且触控目标不少于 40px。
- 使用 `fieldset`、`legend` 和 `label`，不以颜色作为唯一状态提示。
- 深浅主题均维持可读正文对比度和清晰焦点环。
