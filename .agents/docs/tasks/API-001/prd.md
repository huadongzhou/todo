# PRD：Bun/Elysia 服务与共享契约基线

## 目标

为跨端待办应用建立可本地运行的 Bun + Elysia 服务端，以及供客户端和服务端共用的 TypeScript 契约，为后续账号、持久化和同步奠定边界清晰的基础。

## 非目标

- 不实现账号、数据库、生产部署、真实跨设备同步或推送提醒。
- 不修改 Tauri 原生 IPC 的 Rust 单一契约来源。
- 不改变现有待办界面或将客户端目录迁移到 `apps/desktop`。

## 用户故事与验收

1. 开发者可用 `npm run api:dev` 启动 Bun 服务，并从 `GET /health` 得到服务状态。
2. 客户端和服务端可从同一 contracts 包引用同步请求和响应类型。
3. 调用 `POST /v1/sync` 时，非法 payload 被拒绝；同一操作重复提交时只确认一次且 cursor 不重复增长。
4. 开发者可通过 npm 运行客户端检查、共享包检查、服务端检查和服务端测试。
