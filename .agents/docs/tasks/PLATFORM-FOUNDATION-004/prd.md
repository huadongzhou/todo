# 产品需求：全局快捷键与快速新增

## 背景

用户需要从任意桌面场景（甚至在应用已隐藏到托盘后）立即打开待办输入入口。本里程碑补齐：

1. 一条全局快捷键，按下即唤起主界面的快速新增。
2. 该快捷键同时解决上一里程碑推迟的"应用隐藏到托盘后的唤醒"场景。

## 适用范围

- 桌面端：通过 `tauri-plugin-global-shortcut` 注册系统级全局快捷键。
- 浏览器 / 移动端：无全局快捷键 API，逻辑安全跳过。

## 用户故事

- 作为桌面用户，我按下 `Ctrl/Command+Shift+A`（可默认），无论应用当前在托盘、最小化、还是被遮罩，都能在主界面聚焦到输入框。
- 作为桌面用户，我看到一个轻量提示知道这条快捷键是多少。

## 验收标准

- 桌面端注册一条默认全局快捷键 `CommandOrControl+Shift+A`。
- 按下快捷键：主界面可见（若被隐藏则显示），焦点落到待办输入框。
- 应用启动时注册、退出时注销，不遗留 OS 级的快捷键占用。
- 浏览器模式无插件时安全跳过，不阻塞启动。
