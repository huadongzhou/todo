# 截止日与提醒通知设计规格

## 信息架构

- 待办表单新增：截止日（`<input type="date">`）、提醒时间（`<input type="datetime-local">`）。
- 待办列表项右侧：显示截止日徽标；逾期未完成用强调色徽标（红色），临近用中性色。
- 设置面板暂不新增；通知权限在首次请求弹窗（系统原生）。

## 组件与状态

- 编辑表单中：
  - 日期输入控件（截止日）；
  - 日期时间输入控件（提醒时间）；
  - 二者都可独立留空。
- 列表项中：
  - `dueDate` 徽标：显示 `7月20日` / `今天` / `明天` / `逾期 N 天`；
  - 逾期用 `text-red-600`，当日 / 明天用强调色。

## 调度规则

- 创建 / 更新待办时计算 `reminderAt`：
  - 仅提供了 `dueDate` 无 `reminderAt`：不主动推送；
  - 提供了 `reminderAt`：调度一次本地通知。
- 应用启动：重新扫描所有未完成待办，重新调度未过期的提醒。
- 目标值变更：先取消旧的再调度新的。
- 完成 / 删除待办：取消对应的提醒通知。

## 权限与降级

- 首次需要发通知前调用 `requestPermission()`；
- 已授予 → 正常调度；
- 被拒绝 / 失败 → 写 `warn` 级诊断日志，不抛错；UI 不加额外提示；
- 浏览器无插件时，启动阶段先保证桌面插件路径，浏览器路径可暂缓。

## 响应式与无障碍

- 日期 / 时间控件使用原生 `<input>`，键盘可达、对比度合规；
- 徽标不以颜色为唯一提示：搭配文字（"逾期" / "今天"）。
