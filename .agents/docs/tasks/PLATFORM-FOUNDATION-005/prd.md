# PRD：今日桌面卡片

## 目标

在桌面端提供一个独立的“今日待办”卡片窗口，让用户无需打开主界面即可查看并勾选今日截止 / 逾期的未完成待办。卡片作为主界面的轻量补充，不是主界面的替代。

## 范围

### 包含

- 一个独立的 Tauri `WebviewWindow`（标签 `today`），仅桌面端创建。
- 卡片内容：今日截止 + 逾期的未完成待办（`dueDate` 为今天或更早，且 `status === "open"`）。
- 卡片内可完成（toggle）/ 删除单条待办，变更回写到主窗口。
- 主窗口与卡片通过 Tauri event 双向同步，保持数据一致。
- 设置页“桌面行为”组增加“显示今日卡片”开关（默认关闭）。
- 打开卡片时若已存在则聚焦，避免重复创建。

### 不包含

- 每任务一卡片（后续里程碑）。
- 卡片内编辑标题 / 修改截止日 / 设置提醒（保持卡片轻量）。
- 卡片位置自定义拖拽（固定右下角工作区定位）。
- 应用关闭期间的卡片（卡片仅在主窗口运行时存在，数据源为内存中的 Pinia store）。

## 用户故事

- 作为桌面用户，我希望在桌面右下角看到今日待办，以便随时了解当天任务。
- 作为桌面用户，我希望在卡片上直接勾选完成，而无需打开主界面。
- 作为桌面用户，我希望关闭主界面后卡片数据仍与主窗口一致（通过 event 同步）。

## 验收标准

1. 桌面端打开“今日待办”卡片后，列表仅显示今日截止 + 逾期的未完成待办。
2. 在主窗口新增 / 完成 / 删除待办后，卡片列表实时刷新。
3. 在卡片内完成 / 删除待办后，主窗口列表实时刷新。
4. 卡片窗口始终置顶、无边框、跳过任务栏、带阴影。
5. 浏览器 / 移动端不创建卡片，不阻塞启动。
