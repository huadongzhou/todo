# 产品需求：托盘、关闭隐藏与单实例

## 背景

Milestone 1 已交付设置 / 主题 / 诊断日志基础层。本里程碑补齐桌面常驻的三个基础体验：

1. 关闭主界面时隐藏到托盘，而不是退出应用。
2. 托盘作为“桌面控制中心”：快速新增、今日任务数、暂停提醒、显示/隐藏主界面、退出。
3. 应用全局单实例，二次启动只把已有窗口提到前台。

## 适用范围

- 本期仅桌面端需要完整托盘体验。Android / iOS 不显示托盘也没有“关闭隐藏”，设置项在移动端隐藏。
- 托盘图标优先使用内置资源图标（PNG），不引入第三方图标包。如果 `image-png` feature 无法启用，回退到默认图标，但要保证托盘仍可创建。
- 本期桌面卡片仍不实现；托盘只承担轻量控制，不做完整主界面。

## 用户故事

- 作为桌面用户，我关闭主界面后再次打开托盘图标，应用瞬间回到前台。
- 作为桌面用户，我在托盘菜单里看到“今日 N 项待完成”，并可直接快速新增一条。
- 作为桌面用户，双击托盘图标或选择“显示主界面”都能恢复窗口。
- 作为桌面用户，我再次启动应用时不会打开第二个窗口，只会唤醒已有窗口。

## 验收标准

- 桌面端创建系统托盘；托盘菜单至少包含：显示 / 隐藏、快速新增、今日数量、退出。
- 关闭主界面默认隐藏到托盘；可在设置里关闭该行为（直接退出）。
- 托盘丢失时（罕见桌面环境缺陷）退化为直接退出，并写入诊断日志，不崩溃。
- 二次启动应用时，把已有主界面提到前台并聚焦。
- 浏览器开发模式无托盘 API 时，整段逻辑安全跳过，不阻塞应用启动。
