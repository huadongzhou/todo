# 托盘、关闭隐藏与单实例设计规格

## 信息架构

托盘菜单内容（桌面端）：

- 显示 / 隐藏主界面（一项，随状态切换标签）
- 快速新增（命令式，由后续里程碑扩展为弹窗；本里程碑聚焦恢复前台）
- 今日 N 项待完成（只读状态项，禁用交互）
- 分隔线
- 暂停提醒（本里程碑占位，保留后续接入）
- 设置、退出

## 交互

- 双击托盘图标：切换主界面显隐。
- 左键单击托盘图标：打开上下文菜单（默认行为）。
- 关闭主界面按钮：默认隐藏到托盘；设置项关闭时恢复原生退出。
- 二次启动：已有窗口前置并聚焦；不新建窗口。

## 组件与状态

- 设置面板追加“桌面行为”分组：
  - “关闭按钮隐藏到托盘”开关（默认开；仅在桌面端显示）。
- `settingsStore.closeToTray`：布尔，桌面默认 `true`。
- 浏览器 / 移动端不渲染桌面行为分组。
- 托盘故障时写入 `warn` 级诊断日志并回退到原生退出，不阻塞启动。

## 响应式与无障碍

- 托盘本身是平台原生控件，不需要额外 ARIA；UI 设置分组的开关沿用 Milestone 1 的无障碍模式。
- 桌面行为分组仅在 `isTauri()` 时显示。
