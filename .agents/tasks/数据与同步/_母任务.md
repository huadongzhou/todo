# 数据与同步

- 级别：母任务
- 状态：拆解
- 来源方案：.agents/plan/06-数据与同步.md

## 需求（整体）

- 目标与场景：全项目数据底座——端侧 SQLite（rusqlite + command 封装、repository 收口）与 Store 迁移、v1 全字段契约扩展、服务端 SQLite 持久化、备份容灾与监控、登录绑定同步、移动同步接入、ICS 日历集成。W1 首个启动的母任务。
- 范围（做 / 不做）：做 TODO.md 模块 6 全部功能点。不做：各业务字段的语义与界面（归各业务母任务）、同步收费开关（归「发布工程」）。
- 外部前置：01–06、08 无外部依赖（前段可先行）；07 依赖 账号与登录/01–02；10 依赖 移动端形态/01–02。
- 整体验收标准（逐条可检查）：
  - [ ] 端侧与服务端数据在进程重启、断电模拟后零丢失；迁移后旧 Store 数据完整可见。
  - [ ] v1 全字段进 contracts 且为唯一实体来源（src/types/ 无手写实体），types:generate 产物与调用方同步。
  - [ ] 同步在新底座全量回归：离线补推、冲突服务端优先字段级合并，双端最终一致。
  - [ ] 备份可恢复、监控可告警各有一次演练记录；ICS 在至少一个主流日历验证通过。
  - [ ] `cargo test --workspace`、`pnpm run check` 通过；TODO.md 模块 6 状态同步。
