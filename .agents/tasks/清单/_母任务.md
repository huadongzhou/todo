## 需求（整体）

- 目标与场景：清单组织维度全量落地——清单生命周期与侧边栏、单清单归属模型（一任务一清单，多维分类交给标签）、共享协作（邀请/指派/同步通知）。
- 范围（做 / 不做）：做 TODO.md 模块 13 除 13.5 外全部功能点。不做：13.5 多工作区（远期储备）。**编排者 2026-07-23 澄清**：创建与编辑界面的「清单」选择控件由本母任务的 03-任务归属操作 交付，不归 任务管理/02——02 只负责交付一个装得下后续字段的容器与字段块（`TodoFields.vue`），各字段控件由持有其业务语义的子任务自己加进去。原措辞「不做 创建界面清单入口（归任务管理）」与拆解清单 03 的一句话验收「创建与编辑可选清单」自相矛盾，以本澄清为准。
- 外部前置：数据与同步/03（契约）完成；04 起共享段另需 账号与登录/01–02 与 数据与同步/07 完成。
- 整体验收标准（逐条可检查）：
  - [ ] 单清单归属全链一致：任一任务在列表、创建界面、侧边栏筛选、同步后另一端都只属一个清单。
  - [ ] 删除清单不丢任务（回落收件箱），操作可撤销。
  - [ ] 共享段：两个真实账号完成 邀请→接受→双向改动→指派→退出 全链路，数据与通知无错漏；非成员访问被拒。
  - [ ] `cargo test --workspace`（级联与鉴权）、`pnpm run check` 通过；TODO.md 模块 13（除 13.5）状态同步。
