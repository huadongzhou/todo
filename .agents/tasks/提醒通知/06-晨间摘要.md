# 晨间摘要

- 级别：简化
- 状态：设计

## 需求（产品）

- 目标与场景：每日早晨一条汇总通知：今日到期 / 逾期 / 我的一天概览。
- 范围（做 / 不做）：做 定时聚合通知（读统计数据源）；不做 内容个性化。
- 验收标准（逐条可检查）：
  - [ ] 每日定时一条，三段内容与应用内数据一致；无任务时按空态文案处理。

### 编排者并入项（来自 提醒通知/05 UI/UX 阶段，待本任务评估）

**05/06 边界与早晨双通知**：勿扰时段（05）结束时会补推一条「N 条提醒待查看」摘要，而晨间摘要（本任务）也在早晨定时发一条——两者时刻可能相近（如勿扰 8:00 结束、摘要 8:00）。05 已把两者定为正交（事件驱动的被压提醒 vs 定时驱动的统计概览），不合并、不互相替代。

本子任务落地时请评估并定案：① 晨间摘要本身是否受勿扰门控（勿扰期内摘要静默暂存还是照发）；② 05 的补推是否可并入晨间摘要以减少早晨通知数。05 已保证补推走 01 的同一发送判定、可被本任务协调。

补充验收标准：

- [ ] 早晨勿扰结束补推与晨间摘要的关系有明确结论（受门控/合并/分离各择其一并说明），不产生用户困惑的重复早晨通知。
