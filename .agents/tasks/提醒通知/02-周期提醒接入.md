# 周期提醒接入

- 级别：直达
- 状态：开发

## 需求（产品）

- 目标与场景：周期任务每次实例到点均提醒。（外部前置：任务管理/06、/08 完成）
- 范围（做 / 不做）：做 实例生成与调度器联动；不做 规则本体。
- 验收标准（逐条可检查）：
  - [ ] 周期任务连续两次实例均按时提醒（含跨日用例）。

### 编排者并入项（来自 任务管理/12 评审第 1 轮，已裁决「转任务处理」）

**入站同步不重排本端提醒**（`src/stores/todos.ts` 的 `applyRemoteUpsert`）：该函数对任何字段都不触碰提醒排程。`任务管理/12` 接了「锁定任务不排提醒、本地完成/删除/还原前置即重排」，但**远端**完成某前置时，本端依赖任务的提醒不会被重排（本地看仍锁定）。这不是 12 的缺口（既有边界，12 未新增偏差），而是「提醒排程随入站同步刷新」这一面尚未建立。

本子任务把提醒排程接周期实例，请把「入站同步导致的状态变化应触发受影响任务的提醒重排」一并纳入——不只是周期，还包括依赖解锁、远端改提醒时间等。若排程届时已下沉 Rust，则在 Rust 侧的入站合并后重排。

补充验收标准：

- [ ] 远端变更（含完成某前置、改提醒时间、周期推进）经入站同步后，本端受影响任务的提醒被正确重排，不需要重启或本地再操作一次。
