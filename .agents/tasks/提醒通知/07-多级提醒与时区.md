# 多级提醒与时区

- 级别：简化
- 状态：设计

## 需求（产品）

- 目标与场景：同一任务可设多个提醒点（截止前 1 天 / 1 小时 / 15 分钟）；跨时区提醒语义可选（本地时刻 / 固定时刻）。
- 范围（做 / 不做）：做 多提醒点设置与触发、时区策略字段；不做 契约本体（已在 数据与同步/03）。
- 验收标准（逐条可检查）：
  - [ ] 一任务多提醒点全部按时触发。
  - [ ] 修改系统时区后按所选策略正确触发，走查记录在案。

### 编排者并入项（来自 提醒通知/05 评审第 1 轮，已裁决「转任务处理」）

**补推提醒的「【逾期】」文案口径**（`src-tauri/src/reminder_scheduler.rs` 的 `notification_text`/`summary_notification_text`）：05 的勿扰补推里，≥2 条摘要路径刻意去掉了「【逾期】」前缀，但恰 1 条走个别发时仍带该前缀——两路径不一致。规格建议「补推（摘要与单发）都不带该前缀（勿扰晚发是有意为之、标记会误导）」，但把它交给了本子任务与时区一并定。

本子任务读真实时区 offset 收敛逾期判定，届时请把「DND / 时区导致的延迟发送是否算逾期、补推文案摘要与单发是否一致去掉【逾期】」一次定清。

补充验收标准：

- [ ] 补推提醒（勿扰结束的摘要与单发）的「【逾期】」文案口径一致，且与「延迟发送是否算逾期」的产品定义相符。
