# 设置面板

- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计设置面板：外观设置 + 快捷键面板 + 提醒偏好。
- 范围（做 / 不做）：做 外观（主题三档/字号缩放/高对比/完成动效音效）、快捷键设置面板、提醒偏好（默认提醒时间/周起始日/snooze 四档/到期重催/勿扰时段/晨间摘要/时区策略本地固定）；fieldset 分组。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：外观与设置、提醒通知设置
- 验收标准（逐条可检查）：
  - [ ] 设置项按 fieldset 分组、开关/输入形态统一、说明句清晰
  - [ ] 提醒偏好各项（含时刻输入、跨午夜说明）在稿中体现
  - [ ] 导出浅/暗 PNG 到 .agents/design/10-设置面板/

## 规格（UI/UX）

设计与开发合并角色一次产出；令牌逐字取自 DESIGN.md 与设计稿 01/02，已编码项文案与默认值逐字取自 `src/App.vue`（设置面板 fieldset）与 `src/stores/settings.ts`。

### 结构与布局

- 形态：弹层（modal dialog）浮于主界面之上——`surface-card` 对话框居中，压在 40–60% 黑遮罩（`--scrim`：浅 `rgba(2,6,23,0.55)`、暗 `rgba(0,0,0,0.62)`，取 DESIGN 弹层基准）之上，底层用低对比应用剪影示意（非真实内容）。1280 画板、`?dark` 切暗、Inter。
- 对话框三段：头部（标题「设置」18/600 + 副标题 14/次要「个性化应用在此设备上的显示方式。更改即时生效并自动保存。」+ `Esc 关闭` 提示 + 关闭 X icon-btn）／主体（两列 grid，`align-items:start`）／底部（即时生效说明 + `Esc 关闭` + 主按钮「完成」）。
- 本屏范围仅取需求三组，用 `<fieldset>` + `legend`（14/600 + lucide 图标）分组，逐字复用 App.vue 的行结构（flex + gap 12 + min-h 44 + hover 底）：
  - 左列「外观」：主题三档（radio：浅/深/跟随系统，含「当前：跟随系统」状态行）＋「显示」子组：字号缩放（segmented 小/标准/大/特大）、高对比模式、完成动效、完成音效（checkbox）。
  - 左列「快捷键」：说明句 + 键位行（名称 + `kbd` 组合 + 编辑铅笔），含一行「捕获中」态 + 「重置为默认」ghost 按钮。
  - 右列「提醒偏好」：默认提醒时间（time）、周起始日（segmented 周日/周一）、「通知时机」子组（到期重催 checkbox；勿扰时段 checkbox + 开始/结束 time + 「次日」跨午夜说明；晨间摘要 checkbox + 推送时间 time + 说明）、「稍后提醒时长」子组（snooze 四档 checkbox）、「时区策略」子组（本地/固定 radio 二选一）。
- 复用组件：`surface-card`、01 复选框（brand 填充 + 白勾）、01 派生 radio（圆形 + brand 描边 + brand 圆点）、01 focus-ring、01/02 按钮（default/ghost/icon-btn）、02 分段控件（`.segmented/.seg`）、02 `kbd`、02 时间输入形态（`border-0 bg-slate-100`）。

### 状态

- 默认：主题「跟随系统」选中；字号缩放「标准」、周起始日「周一」；完成动效开、其余外观关；提醒组勿扰/晨间/四档 snooze 开、到期重催关、时区「本地时间」。以上默认值逐字对齐 `settings.ts` 的 ref 初值。
- 悬停：主题「深色」行与快捷键「删除任务」编辑铅笔以 `--row-hover`（slate-50 / 暗 slate-900）呈 hover 底，示范行 hover 反馈。
- 聚焦：勿扰「开始 22:00」time 输入示范 focus-ring（2px sky-500 + 2px offset，暗色 offset slate-950）。
- 展开/条件态：勿扰时段、晨间摘要为「开启」，随之展开时间输入（复刻 App.vue `v-if` 展开逻辑）；快捷键「全局快速捕获」呈捕获中输入态（brand 边框 + 录制点 + 「按下新的快捷键…」）。
- 空/加载/错误：本屏为纯设置面板，无列表数据故无空态/骨架；错误态在此为字段级（沿用 01/03 表单错误规范），本稿未触发具体校验错误，仅在说明中标注遵循既有规范。

### 暗色适配

- 全令牌浅暗成对（`:root` / `.dark` 两套，值逐字取自 01/02）：页面 slate-50/950、卡片 white/slate-950、正文 slate-900/200、次要 slate-600/300、边框 slate-200/800；遮罩暗色加深至 0.62 保证前景隔离；分段活动段暗色用 slate-800 抬升（卡片=页面同色）；时间输入底 slate-100/900。`?dark` 一键切换，dark.png 已成对导出并自检。

### 移动端适配

- 所有可点目标 ≥ 44px：设置行 min-h 44、time 输入 min-h 44、分段 seg min-h 40（含 padding 达标）、icon/编辑按钮 40–44。
- 弹层移动端形态：桌面居中 modal，移动端应转为底部抽屉 + 下滑关闭（DESIGN 弹层基准），本稿以 1280 桌面画板呈现，两列在窄屏应回落为单列纵向堆叠（fieldset 顺序：外观 → 快捷键 → 提醒偏好）。正文与输入字号 ≥ 14/16，符合移动端不小于 16 的输入基准。

### 可访问性

- 每个设置项均有可见文字标签与说明句；`<fieldset>`+`<legend>` 语义分组，`aria-labelledby` 关联；主题/时区/周起始日为单选语义。
- 关闭途径双通道：头部 X（`aria-label="关闭设置"`）+ 底部「完成」，并显式 `Esc 关闭` 提示（DESIGN 弹层「按钮 + Esc」基准）；`role="dialog" aria-modal="true"` + `aria-labelledby/-describedby`。
- 状态不孤用颜色：选中/开启均有对勾或圆点 + 文字；「次日」以加粗文字点明跨午夜，非仅靠颜色。
- 焦点环任何可交互元素聚焦均显示、不移除；`kbd` 键位为文本可读。

### 令牌溯源与 DESIGN.md 缺口（报告编排者）

- 稿内未私自造色，全部取既有令牌；缺口以在稿「设计说明」amber 标注块记录，均属**未编码项落地实现前需先补 DESIGN.md** 的规则空白，非本稿新增令牌：
  1. 字号缩放：现字号阶梯（12/14/16/18/24/32）为固定值，缩放档位与作用范围未定义。
  2. 高对比模式：现中性/语义色阶未含高对比变体，需定义高对比调色板。
  3. 完成动效/音效：需在 DESIGN.md「动效」节补交互与音频规格。
  4. 快捷键默认键位表：未在 DESIGN.md/代码固化（本稿「全局快速捕获」沿用 02 的 Ctrl+Shift+Space 语义占位）。
- 结构性提示（不改代码，供编排者裁决）：① 单选 radio 组件 01 未定义，本稿派生自 01 复选框令牌（非新增令牌）；② 时区策略现状代码为单一 checkbox「按固定时刻触发提醒」，本稿按需求呈「本地/固定」二选一 radio（二态语义等价、文案不变），若复现需与代码严格一致则应回退为 checkbox；③ App.vue 同面板中的桌面行为/同步/日历三组归属其他模块（同步→02、桌面→13），本屏按需求聚焦外观/快捷键/提醒未纳入。
