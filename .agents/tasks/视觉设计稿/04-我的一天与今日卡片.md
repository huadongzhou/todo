### 结构与布局

本屏一张 1280 画板，三块：

1. **我的一天页（应用窗，有内容态）**——复用 02 的导航壳（侧栏 + 顶栏），侧栏「今天」项改标签为「我的一天」（唯一今日入口，7.5）并置活动态（复用 02 sun 图标 + `nav-item.active` 的 info 令牌底/字）。主区为「我的一天」页：
   - **页头**：`24/600` 标题「我的一天」+ `14` 次要说明 + 右侧唯一主操作按钮「＋ 挑选任务」（brand 底白字，即今日清单的「增删入口」中的「增」；沿用 02 side-cta + 内容 CTA 双 brand 的既有布局节奏）。
   - **今日概览（数据卡）**：`surface-card` 内四格统计条（今日挑选 / 今日到期 / 逾期 / 已完成），大数字 `30/700 tabular-nums`；到期用 `--soon-fg`、逾期用 `--overdue-fg`、已完成用 `--success-fg`（均带文字标签，色彩不孤用）。右上「同源」胶囊（info 令牌 + link 图标）+ 卡底 `caption` 明示「计数与列表到期徽标、成就页统计读同一口径（`src/lib/dueDate.ts`）」——满足「与统计单源、视觉标注数据来源」。
   - **三处联动入口提示**：info 令牌底色条，前置「三处联动都指向『我的一天』」+ 三枚 `lk-chip`（晨间摘要 推它 / 时间块 排它 / 月历表·今日卡片 显它），对应 7.5「联动收敛」。
   - **今日清单**：区块标题「今日清单」+ 计数；`surface-card` 列表，待办行逐字复用 02 `.row/.circle/.badge/.row-title`——完成圈 + 标题 + 到期徽标（三档语义色）+ 标签/周期 pill；行尾操作为单枚「移出今日」`icon-btn`（lucide circle-minus，即「增删入口」中的「删=移出今日」，与「删除任务」区分）。含 1 条已完成行（降对比 + 删除线 + 到期呈无 tone 纯文本，忠实复刻现状）。
2. **空态板 + 联动收敛说明**（两列 `surface-card panel`）：左列空态——概览四格归零 + `empty` 引导（sun 图标圆底 + 「今天还没有挑选任务」+ 说明 + 「＋ 挑选任务」CTA）；右列以图标列表说明三处联动如何收敛到「我的一天」。
3. **今日桌面卡片**（分隔标题 + 三枚 340px 窄卡）：逐字复刻 `TodayCard.vue`——`surface-card`、头部强调方块（`ClipboardList` + 今日待办 + 「N 项待完成」）+ 列表行（完成圈 + 标题截断 + 到期 tone 徽标 + 删除 icon）。三态：**展开态**（完整清单，含 hover 行与删除 hover 红）/ **收起态**（仅头部汇总 + 「点击展开」占位，收起用 chevron-right）/ **空态**（sky 圆底对勾 + 「今日暂无待办 / 享受你的清闲时光。」，与 TodayCard 空态逐字一致）。

### 状态

- **待办行/卡片行**：默认；**悬停**——列表行 `--nested-bg`、卡片行 `hover:bg-slate-50/slate-900`（已在展开卡首行示意）；**聚焦**——任何可交互元素显示 `focus-ring`（2px sky-500 + 2px offset，暗色 offset slate-950）；**完成态**——降对比 + 删除线（`.row-title.done` slate-400/500），完成圈 brand 填充 + 白勾。
- **删除/移出**：卡片删除 icon 默认 `--icon-muted`、hover `--danger-fg`（red-600/red-400，已在展开卡首行示意）；我的一天页行尾为「移出今日」（circle-minus，非破坏，默认 muted）。
- **空数据**：我的一天页空态（概览归零 + 挑选引导）；今日卡片空态（今日暂无待办）。二者均给下一步/安抚文案，不留白屏。
- **加载**：沿用 01 骨架语言（列表 300ms 以上显示骨架，占位与真实行同构）；本稿以静态态为主，加载态引用 01 骨架规格，不重复绘制。
- **错误**：本屏无独立错误态；存储/同步告警条形态归 02（错误提示条 red 语义），不在本屏重复。

### 暗色适配

`?dark` 切换，全量令牌浅暗成对（见 `light.png` / `dark.png`）：页面/卡片 slate-950、正文 slate-200、边框 slate-800、语义色「900/40 底 + 300 字」。今日卡片强调方块与空态圆底：浅色 `sky-100 底 + sky-600 字`（与 TodayCard 代码一致），暗色按 DESIGN info 令牌对补齐为 `sky-900/40 底 + sky-300 字`（降饱和变体，非反色）——见「实现记录」中的实现对齐提示。

### 移动端适配

- 触控目标：完成圈 24px 但行 padding 使命中区 ≥44px；主操作/挑选按钮高 44px；卡片删除/收起 icon 命中区补至 ≥30–44px。相邻可点目标间隙 ≥8px。
- 正文 ≥16px（列表行标题 16、卡片行标题 14 属窄窗紧凑态，仍 ≥ DESIGN 移动正文下限的桌面卡片语境）。概览四格在窄屏应回落为 2×2（本稿桌面 1280 呈一行四格，移动断点由复现阶段按 `stat-strip` 网格自适应）。
- 今日卡片本就是 320–360px 窄窗，天然适配移动侧「今日」小组件比例；禁止横向滚动，标题用截断。

### 可访问性

- 语义信息（到期/逾期/完成/同源）均文字 + 图标伴随，色彩不孤用（符合 DESIGN 可访问性基准）。
- 纯图标按钮全部带 `aria-label`（移出今日 / 删除 <标题> / 收起·展开今日卡片 / 立即同步 / 挑选任务）；收起按钮带 `aria-expanded`。
- 对比：正文与语义徽标沿用 01/02 已验证令牌（≥4.5:1）；侧栏活动项、info 条用 info 令牌对。
- 键盘：Tab 顺序随视觉顺序；聚焦显示 `focus-ring`，不移除。
- 已知偏差沿用 DESIGN：`default`/brand 底白字对比约 2.6:1 未达 AA——本屏 brand 按钮（新建/挑选/CTA）沿用现状，待编排者对 01 的同一待决统一裁决，不在本屏私自改色。
