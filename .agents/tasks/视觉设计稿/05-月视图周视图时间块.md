- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计月历视图、周视图与今日时间块（时间轴）。
- 范围（做 / 不做）：做 月视图（按日分布 + 完成标记 + 月份切换）、周视图（七列 + 周起始日偏好）、时间块（今日时间轴 + 任务拖入安排 + 与时间段字段互通）；各含空态。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：视图与统计/04/05/13

  - [ ] 月/周/时间块三视图分布正确，数字与统计单源一致（视觉上标注数据来源）
  - [ ] 周起始日偏好在稿中体现；时间块与任务时间段呼应
  - [ ] 导出浅/暗 PNG 到 .agents/design/05-月视图周视图时间块/

## 规格（UI/UX）

一致性底座：逐字复用 01（令牌/组件）与 02（待办行/徽标/语义色/空态语言）；三视图均未编码，本稿为其复现参照。基准日期 2026-07-25（周六，今日）。**无新增设计令牌**——月/周/时间块所需视觉元素（语义色三档 + 成功 emerald、pill、卡片、今日高亮、空态）DESIGN.md 与 01/02 已全覆盖。

### 结构与布局

- **画板**：1280px，`surface-card` 抬头 + 三个视图区块 + 空态三连区块，纵向堆叠（同 01/02 版式）。每区块顶部 `section-title`（idx 徽标 + 标题）+ `src-note` 数据源标注行。
- **月视图**：`nav-cluster`（‹ 2026 年 7 月 › + 回今天）+ 周起始 `cfg-note` 胶囊；`weekday-row`（一…日，周末列头弱化）+ 7×5 `month-grid`。单元格 `.mcell`：日号 + 当日计数（>3 显示）；任务用 `.mtask` 小胶囊（语义底色 + 6px 语义点 / 完成态 emerald 底 + 勾 + 删除线）；上/下月日期 `.other` 弱化；今日日号 brand 圆点；当日过多用 `+N 更多` 折叠。底部语义图例 + 月度汇总条（本月/已完成/逾期/完成率，标注直读统计 selector）。
- **周视图**：`nav-cluster`（‹ 7 月 20 日–26 日 › + 回本周）+ 周起始 `cfg-note`；`week-grid` = 48px 分区标签列 + 7 日列。表头 = 星期 + 日号（今日 brand 圆点 + 列头 info-bg）；两分区行「全天 / 定时」，任务 `.wtask` 胶囊（定时带 `wtime` 时刻前缀，列内按时间先后）；今日列整列 info-bg 弱高亮。底部图例（全天/定时/今日高亮）。
- **时间块**：`tb-wrap` = 左时间轴（1fr）+ 右未排期区（300px）。时间轴 08:00–19:00 每小时 56px 刻度，任务块绝对定位（top=(起时−8)×56，height=时长×56），语义底色 + 起止时刻 + 时长；空闲槽 `.b-free` 斜纹虚线 + 「可拖入安排」。右侧 `unsched` = 标题 + 计数 + `drop-hint`（拖入即写起止时刻）+ 3 张 `.ucard`（grip 手柄 + 标题 + 到期/估时徽标，`cursor: grab`）。
- **空态三连**：`states-grid` 三卡，各含 `.empty`（图标 + 标题 + 引导语，月视图卡带「新建任务」CTA）。

### 状态

- **默认**：三视图主态如上；语义色伴随图标/文字，不孤用颜色（DESIGN 可访问性基准）。
- **完成**：月/周任务显 emerald 底 + 勾 + 删除线（复用 02 完成行语义）；时间块完成块 `.b-done` emerald 底 + 勾 + 标题删除线。
- **今日高亮**：月视图日号 brand 圆点；周视图今日列 info-bg + 日号 brand 圆点；时间块头「今天」amber 胶囊。
- **折叠（+N）**：当日任务 >可视条数时尾部 `+N 更多`（月视图今日示范 +2）。
- **空数据**：月「本月还没有待办」、周「本周暂无安排」、时间块「今日暂无时间块」，均带下一步引导。
- **悬停/聚焦/加载**：本稿为静态视觉参照，交互态沿用 01 组件库既定 hover/`focus-ring`/骨架规范，不在本稿重复铺陈（区块级视觉稿，非逐控件态板）。

### 暗色适配

`?dark` 切 `.dark`，令牌成对：页面 slate-950、卡片 slate-950 靠边框分层、语义色切「900/40 底 + 300 字」、语义点切亮档（red-400/amber-400/slate-500/emerald-400）、今日/信息高亮 sky-900/40。浅暗两版均已导出并 Read 自检。

### 移动端适配

本稿为桌面 1280 画板（视图与统计/13 桌面时间块 + 04/05 月周视图，桌面形态）；移动端月/周/时间块的窄屏排布（月视图点密度、周视图横滑、时间块单列）归移动端主要屏（14）承接，本稿不铺陈。所有可点目标（nav-arrow 36、btn-today 36、ucard 拖拽区）在桌面达标；移动复现时按 DESIGN 触控 ≥44px 扩展。

### 可访问性

- nav-arrow 纯图标按钮带 `aria-label`（上/下月、上/下周）；grip 手柄 `aria-hidden`（拖拽为增强，非唯一路径）。
- 语义状态（逾期/今天/完成）均文字或图标伴随，色彩不孤用；数字用 `tabular-nums`。
- 正文/次要文字对比沿用 01/02 已验证令牌（slate-900/600 压浅底、slate-200/300 压暗底 ≥4.5:1）；语义胶囊沿用 DESIGN 三档配比。

### 数据源单源（验收要点）

三视图数字/分布均标注「数据源：统计 selector（视图与统计/03 统一口径）」，与列表/成就页/月历/卡片同源，视图不自算；月度汇总条显式标注「同『本月』口径直读统计 selector，与成就页数字一致」。
