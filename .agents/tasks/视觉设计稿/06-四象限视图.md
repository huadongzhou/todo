### 结构与布局

- 复用 02 主窗壳：侧栏（`.sidebar` 逐字沿用）+ 主区顶栏。顶栏 segmented 沿用 02 视觉，本屏为视图切换 `列表 | 日历 | 四象限`，`四象限` 激活（`.seg.active`，暗色 slate-800 抬升）。
- 四格矩阵 `.board`：`grid` = 左轴栏 32px + 两列 1fr；顶轴行 + 两象限行。轴用**位置 + 文字**编码：顶轴 `紧急`（左列）/`不紧急`（右列），左轴 `重要`（上行）/`不重要`（下行），配 `紧迫程度 →` / `重要程度 ↑` 辅注。四格位置固定：左上重要且紧急、右上重要不紧急、左下不重要紧急、右下不重要不紧急。
- 象限卡 `.qcard` = `surface-card`；头部 `.qhead`（白/slate-950 面）含 2px 顶部彩色细线 + 8px 圆点 + 象限全名（16/600）+ 计数 + 中性 slate 动作胶囊（先做/计划/快速处理/少做，四格统一 `normal` 胶囊，不靠颜色）；主体 `.qbody` 为 `nested-bg` 内凹区（浅 slate-50 / 暗 slate-900），承载任务卡。
- 任务卡 `.tcard` = 待办行的卡片化复用：`card-bg` 面 + 1px 边框 + `shadow-sm` + `rounded-lg`（白卡浮于 slate-50 内凹区，沿用「白卡衬 slate-50」既有关系）；内含完成圈（24px，`circle`/`circle.checked` 逐字复刻 TodoItem）+ 标题（16/1.4，完成态 slate-400 删除线）+ 到期/周期/streak/子任务徽标（`badge.due-*`、`pill-slate`、`pill-emerald` 逐字复用 02）+ 右侧拖拽手柄 `grip-vertical`（slate-400 静默，hover 加深）。
- 未分类托盘 `.untray`：矩阵下方整条 `surface-card`，横排紧凑 chip（未设重要/紧急的任务），文案「未分类 · N 项 — 拖到上方象限，或点卡片设为分类」。
- 象限强调梯度（辅助，非唯一区分）：顶线/圆点取既有语义 fg 令牌自动浅暗成对——重要且紧急 `--overdue-fg`、重要不紧急 `--info-fg`、不重要紧急 `--soon-fg`、不重要不紧急 `--normal-fg`。识别以文字全名 + 位置为主，颜色仅辅。

### 状态

- 默认：四格含卡；右下「不重要不紧急」呈空象限态。
- 悬停：任务卡 hover 抬升（保持 `shadow-sm`，不新增阴影档）、右侧 grip 加深；象限内新建入口 hover ghost 底。
- 拖拽（核心）：拖起卡 `.tcard.dragging` = `shadow-sm` + 2px 品牌 `focus-ring` 环 + opacity .96 表达「抓起」（不自造大阴影，用环表达抬升）；源位留 2px 虚线占位 `.drop-gap`；目标象限 `.qbody.drop-target` 高亮 = `info-bg` 底 + 2px 虚线品牌边 + 居中「松开放入「重要不紧急」」+ 加号图标。
- 快速设置入口：任务卡「优先级」触发（`sliders` 图标按钮）→ `.pop` 浮层（`surface-card` + `shadow-sm`）：标题「设置优先级」+ 关闭 x；`重要`、`紧急` 两行开关（`switch`/`switch.on` 复用 01）；结果行「→ 徽标」；分隔线；ghost「清除分类（移出矩阵）」= 将两布尔置空、退回未分类。
- 空象限：`.empty` 语言（图标 + 「这个象限空着」+ 引导文案 + ghost「新建到此象限」），不留白格。
- 加载：沿用 01 骨架语言（本稿以静态态呈现，规格标注加载>300ms 显骨架）。
- 错误：象限内不单独设错误态；数据/存储错误沿用 02 顶部 `alert.error` 告警条。

### 暗色适配

- 全量走 02 的 CSS 变量集：`page-bg/card-bg/nested-bg/text/border/overdue|soon|normal|success|info-*` 浅暗成对，`?dark` 切换。象限顶线/圆点用语义 fg 变量自动浅暗成对。拖拽目标高亮 `info-bg` 暗色为 `sky-900/40`，焦点环 offset 暗色 slate-950。

### 移动端适配

- 桌面 2×2；窄屏（<768）降为单列纵向四段，象限保留全名标题 + 圆点，轴辅注改行内文字（「重要 · 紧急」等）；任务卡触控区、完成圈、grip、优先级按钮命中区 ≥ 44px，相邻 ≥ 8px；正文 ≥ 16px。拖拽在触屏以长按抓起（规格标注，静态稿不演示手势）。未分类托盘窄屏改纵向列表。

### 可访问性

- 每个象限为带可访问名的 region（`aria-label="重要且紧急"` 等），标题 `h3`；轴标签为文字，象限识别不孤靠颜色（文字全名 + 位置 + 语义徽标图标）。
- 拖拽提供键盘替代：卡片可聚焦，`空格` 抓起/放下、方向键选目标象限（规格标注）；`focus-ring` 全程可见。
- grip / 优先级 / 关闭 x 等纯图标按钮带 `aria-label`，命中区 44px。
- 拖拽目标与结果变化经 `aria-live` 播报（规格标注）；开关 `role=switch` + `aria-checked`。
- 到期/逾期/完成等状态文字+图标伴随，色彩不孤用。
