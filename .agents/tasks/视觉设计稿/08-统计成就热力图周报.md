# 统计成就热力图周报

- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计成就页：统计数据卡 + 热力图 + streak + 周报 + 徽章 + 拖延洞察 + 分享卡片。
- 范围（做 / 不做）：做 成就页单页收拢：顶部数据卡（当日/周/月任务数与完成率）、热力图（贡献格）、连续记录 streak、周报模板、里程碑徽章、拖延洞察、可导出的分享卡片；含空数据/首周边界态。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：视图与统计/03/07/08/09/10
- 验收标准（逐条可检查）：
  - [ ] 单页收拢全部激励能力，数据卡与其他视图统计单源一致（视觉标注）
  - [ ] 热力图/streak/分享卡片形态齐备；空数据态正常
  - [ ] 导出浅/暗 PNG 到 .agents/design/08-统计成就热力图周报/

## 规格（UI/UX）

一致性底座：逐字复用 `01-设计基础与组件库` 与 `02-主窗壳与列表视图` 的令牌、导航壳、徽标、卡片/徽章/提示条/空态/段控件视觉语言。成就页嵌入 02 同款应用窗（侧栏「成就」为激活项），主区收拢全部激励能力；边界态另置状态板（沿用 02「app-window + states」两段结构）。

### 结构与布局

- **抬头 masthead**：复用 01/02 masthead（标题 32/700 + lead + mode-badge）。
- **应用窗（导航壳）**：复用 02 sidebar（256px、brand 徽标、side-cta、清单/标签/更多分组），本页「成就」nav-item `.active`（info 底/字）。主区 topbar 左为页标题「成就」、右为「导出周报」ghost + 「分享成就卡」primary。
- **主区内容（成就页，纵向流，双列处用 `.grid-2` 1fr/1fr）**：
  1. **顶部数据卡**：`.stat-row` 三卡（今日/本周/月）——`stat-num` 40/700 tabular-nums + `unit` 次要 + `rate-pill`（success/normal 语义）+ `progress` 迷你条。右上 `source-chip`（info 胶囊）标注「数据源：统计 selector（与视图·统计单源）」，落实验收「统计单源一致（视觉标注）」。
  2. **热力图**：贡献格日历（53 列×7 行，近一年），左侧周几（一/三/五）、顶部月份标签、右下 `hm-legend`「少→多」五档 + 逐格 `title` tooltip（色不孤用）；卡头 `segmented`（近一年/近6月/近3月，复用 02 段控件）。
  3. **连续记录 streak**：`flame-pill`（火焰 emerald 胶囊，复用 02 `pill-emerald` 语言）「连续 12 天」+ 最长记录 21 天 + 本周 7 日勾选条（今天带 focus-ring 圈选）。
  4. **周报模板**：`auto-badge`（info「自动生成」）+ 三统计（完成/完成率/专注）+ 亮点列表（emerald 勾）——自动生成态。
  5. **里程碑徽章**：`badge-wall` 3 列徽章墙，已获（success/brand disc）与未获（`.locked` 降透明 + lock 图标）。
  6. **拖延洞察**：顺延/改期/卡壳三统计（amber/red/正文）+ 顺延·改期条形 + `alert.warn` 卡壳提示。
  7. **分享卡片**：`share-card` 纯色扁平深底卡面（slate-900，无渐变）+ 大数字（emerald）+ 迷你热力条 + 导出/复制按钮 + 卡面变体 chip + 本地渲染说明。
- **状态板**：`.states` 双列——空数据态（数据卡归零 + 全空热力图 + 空态引导）、首周边界态（迷你统计 + 稀疏热力图 + streak=最长=3 + info 起步鼓励）。状态板小面板宽约 540px，热力图用 `.hm-cal.compact`（8px 格）容纳整年。

### 状态

- 默认：满数据成就页（主态）。
- 悬停：热力图逐格 `title` tooltip；ghost/icon 按钮 hover 底色（复用 02）。
- 聚焦：streak 今日格 focus-ring（2px sky-500 环 + offset），段控件/按钮聚焦沿用 01 focus-ring。
- 加载：沿用 01 骨架语言（超 300ms 显示，本稿未单列骨架屏，复用既有组件）。
- 空数据：状态板「空数据态」——热力图全空 + 归零卡 + 「还没有成就数据」空态 + 主 CTA。
- 首周边界：状态板「首周边界态」——仅最近几天点亮、streak 与最长相等、周报起步鼓励。

### 暗色适配（与浅色成对）

- 全量复用 01/02 暗色令牌（页面/卡片 slate-950、边框 slate-800、正文 slate-200 等）。
- 热力图色阶暗色反向（亮度随完成量升高）：空 slate-800 → emerald-900/700/500/300，端点复用既有 success 令牌（`success-bg`/`success-fg`）。
- 语义徽章/提示条/段控件活动态均取 01/02 暗色成对值；分享卡面浅暗一致固定深底（作为可导出资产，非应用 chrome）。

### 移动端适配

- 桌面视觉稿（1280 画板）；移动版由 14 号「移动端主要屏」承接。窄屏落地建议：`stat-row`/`grid-2`/`badge-wall` 降为单列；热力图容器 `overflow-x:auto` 横向滚动不撑破视口；触控目标（段控件/按钮/徽章）保持 ≥44px；正文 ≥16px。

### 可访问性

- 热力图容器 `role="img"` + 概括 `aria-label`；逐格 `title` 提供数值，颜色不孤用（附图例 + tooltip + 逐格数值）。
- 数据/状态语义均带文字或图标（完成率、顺延、卡壳、徽章解锁条件）；纯图标按钮/分享卡 `aria-label`。
- 段控件 `role="tablist"/tab"`、nav-item `aria-current="page"`、streak 今日格可见 focus-ring；Tab 顺序与视觉一致。
