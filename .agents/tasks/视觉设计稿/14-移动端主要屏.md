## 规格（UI/UX）

<!-- UI/UX 阶段：以 DESIGN.md 令牌 + 该屏已有文字 UI/UX 规格（若模块已编码）/现状代码为输入，给出本屏的构图、状态清单、浅暗与移动适配、可访问性；不新增令牌，缺口停下报告。 -->

移动端不是另造一套视觉，而是把桌面 01/02/03 的令牌、待办行与字段块「移动适配」：单列、控件全宽、触控放大、safe-area 避让。所有色值/字号/间距逐字取自 DESIGN.md 与 01·02·03 的 `:root` / `.dark` 变量，未引入新令牌。

### 结构与布局（画板：多手机屏并排，390px 宽 / 812px 高，圆角外框 + safe-area 示意）

- **移动主屏**：safe-area 顶部状态栏（44px 避让）→ 顶部品牌 + 头像 + 快速新增 pill（全宽输入 + 圆形加号，均 ≥44px）→ 日期分组列表（逾期/今天/明天，复用 02 待办行的移动适配：圆圈 24px、标题 16px、徽标换行不横滚、整行触控 ≥56px）→ 底部三段导航（任务/视图/我的，栏高 56 + home indicator 24），活动段用 info（sky）色。
- **移动创建界面**：顶栏（取消 / 标题 / 展开 slider）→ 单列字段块（标题+计数、备注 textarea、时间组：截止日/估时/重复/提醒、归类组：标签 chip 换行/象限/清单），控件全宽、输入字号 16px 防 iOS 缩放 → 底部固定全宽主 CTA「添加任务」（单屏单一主操作）+ home indicator。内容超一屏纵向滚动，无横向滚动。
- **我的页**：顶部「我的」标题 → 账号卡（头像/昵称/邮箱/登录同步 chip，surface-card）→ 统计三宫格（连续天数/本周完成/总完成，tabular-nums）→ 设置入口列表（账号与同步/外观/提醒偏好/专注计时/快捷键/关于，行 = 图标+标签+chevron，整行 ≥44px）→ 底部导航「我的」活动。
- **滑动手势**：左滑露出右侧「完成」动作条、右滑露出左侧「删除」动作条；动作条为实心语义色 + 白色图标 + 文字标签（信息不单靠颜色）。
- **主屏小组件**：iOS/Android 小 + 中尺寸卡（今日待办计数 + 预览行），置于扁平壁纸底衬，标注「平台限定：iOS WidgetKit / Android Glance」。
- **safe-area 适配**：独立示意屏，顶部 `env(safe-area-inset-top)`（刘海/状态栏）与底部 `env(safe-area-inset-bottom)`（home indicator/手势条）避让带用 info-bg 半透明 + 虚线标注。
- **平板分栏（768 断点）**：列表主栏 + 详情/创建副栏双栏；副栏字段用 grid2 两列（宽度允许时回到桌面双列）。

### 状态

- 待办行：默认 / 完成（降对比 slate-400 + 删除线，复刻 02）/ 逾期（red 徽标）/ 临近（amber）/ 常规（slate）/ 锁定（待前置完成 slate 徽标）。
- 滑动：静止 / 左滑进行中（露绿）/ 右滑进行中（露红）。
- 创建：默认 / 聚焦（focus-ring 或控件内环）/ 校验错误（红字紧贴字段下方，沿用 03）。
- 空态：列表为空复用 01/02 空态语言（说明 + 回车/加号引导）。
- 同步：底栏/账号卡状态 chip（已同步/同步中/失败/未同步），带文字。

### 暗色适配

全部成对：页面 slate-50/950、卡片 white/slate-950、边框 slate-200/800、正文 slate-900/200、次要 slate-600/300；语义徽标浅「100 底 700 字」/ 暗「900·40 底 300 字」。滑动动作条为实心语义色（完成 emerald-700 `#047857`、删除 red-600 `#dc2626`，均为 DESIGN.md 已有令牌值 + 白字），按平台惯例不随主题翻转，白字对比 ≥4.5:1。

### 移动端适配

触控目标 ≥44×44px（图标按钮、tab、圆圈命中区靠 padding 补足）；输入/选择/文本域字号 16px 防 iOS 聚焦缩放；徽标 flex-wrap 不产生横向滚动；固定顶/底栏为内容预留 safe-area 内边距，优先 `min-h-dvh`；断点 375（手机）/768（平板）。

### 可访问性

图标按钮带 `aria-label`；tab 用 `aria-current`/`role`；焦点显示 focus-ring；状态（逾期/完成/同步/删除）均文字+图标伴随，不孤用颜色；分组列表语义化标题；对比浅暗分别验证 ≥4.5:1。

### DESIGN.md 缺口（报告编排者，未私自补令牌）

- DESIGN.md「待补充」已列明「移动端 safe-area 细则（刘海、手势条避让）：待 iOS/Android 构建落地时按实机补充」。本稿以 `env(safe-area-inset-*)` + 既有 4/8 间距节奏（顶 44 / 底 34 示意）作占位表达，未新增颜色/尺寸令牌；实机落地后建议在 DESIGN.md 固化具体 inset 基准值。
- 滑动动作条把语义 700 色值当实心填充使用（完成 `#047857` / 删除 `#dc2626`，均属现有令牌 hex），属既有令牌的新用法而非新色；如需正式化「破坏性/完成动作实心底 + 白字」为组件基准，建议在 DESIGN.md「组件视觉基准」增补一条。
