本屏为「先设计→后复现」的系统集成形态参照（迷你捕捉窗/托盘/角标/跳转列表属客户端 command 与窗口能力，Win11 小组件/Mica 属平台原生工程）。令牌逐字取自 DESIGN.md 与设计稿 01/02/04；今日卡片已在 04，本屏聚焦其余小部件与系统集成。

### 一致性底座（复用，不另造）

- 卡片一律 `surface-card`（rounded-xl + 1px 边框 + shadow-sm 唯一一档）；页面/卡片/嵌套/正文/次要/边框中性色、语义色（overdue/soon/normal/success/info 的浅暗对）、ghost/icon-btn、focus-ring、kbd、空态语言全部逐字取自 01/02/04 令牌变量块。
- 分区用 01/03/07/09 同款 `section-title`（sky idx 徽标 + 24/600 标题 + 13 次要说明）；抬头用同款 masthead + mode-badge；平台限定标注复用 01 `pending`（amber soon 语义 + alert-triangle）。
- 待办行/今日卡片行逐字复刻 02 `.row` 与 04 `TodayCard`（勾选圈 slate-300 描边、标题 slate-700/dark slate-200、到期胶囊语义色、完成态降对比+删除线）。图标唯一源 lucide 描边，尺寸 16 内联/18 菜单项/20 按钮。
- 新增「系统外观中性示意底」`--os-bg`（slate-200/dark slate-900）+ `--os-hatch`（slate-300/dark slate-700）仅用于把桌面/任务栏/Widgets 板/Mica 材质示意为**系统层**，取自 slate 阶既有色、非新增品牌/语义 hue，且明确标注「非应用令牌」；任务书要求「用中性卡示意系统外观」，此为其落地。

### 结构与布局（五区，单 1280 画板纵向排列，区间 1px 分隔线）

1. **迷你捕捉窗**：窄浮窗（420px surface-card）= 头（brand logo + 「快速添加」+ `Esc 关闭`）/ 大输入（48px、input-bg slate-100）/ 可选项胶囊行（截止日期、清单）/ 底（`Enter` 提示 + 取消 + 添加）。置于中性桌面底衬示意「全局快捷键浮层」。
2. **托盘菜单**：中性任务栏图标条（app 图标高亮）+ 弹出菜单（248px）= 头（brand + 今日待办数）/ 快速新增（带 `Ctrl+Shift+Space`）/ 打开主窗 / 分隔 / 退出（破坏性）。
3. **任务栏角标 + 跳转列表**：左卡=图标角标（sky 未完成数 / red 含逾期 / 无角标三例，中性任务栏底衬）；右卡=跳转列表（248px，分组标签「任务」→ 快速新增 / 今天[计数] / 打开主窗），复用托盘菜单视觉。
4. **Win11 小组件**：平台限定条 + Widgets 板中性底 + 小尺寸（232px，顶 2 项+汇总）/ 中尺寸（372px，完整清单+底部快速新增）/ 空态；卡内复用今日卡片行与到期语义色。
5. **Mica 视觉融合**：平台限定条 + 融合示意窗（聚焦态：标题栏/侧栏为 Mica 斜纹材质、内容卡仍 surface-card 不透明；失焦态：Mica 回落纯色 nested-bg）+ 层次图例（① 桌面壁纸 ② Mica 合成材质 ③ 应用内容表面）+ 与 surface 令牌关系说明。

### 状态清单（常态/激活态 + 空/禁用）

- 捕捉窗：常态（空输入自动聚焦、可选项未选、「添加」禁用 opacity-50）/ 激活态（已输入 + 选中「今天 18:00」info 底 + 「工作」清单、「添加」可用 + 取消可见）。
- 托盘菜单：常态（无 hover）/ 激活态（快速新增 hover 浅底、退出 hover 转 red 语义）。
- 角标：未完成（sky）/ 含逾期（red 语义）/ 全部完成（无角标）。跳转列表：常态 + 悬停项浅底。
- 小组件：小尺寸有内容 / 中尺寸有内容 / 空态（复用今日卡片「今日暂无待办」文案）。
- Mica：窗口聚焦（材质生效）/ 失焦（回落纯色），对应 Windows 实际行为，即本屏的「常态/激活态」轴。

### 暗色适配（与浅色成对）

- 全部走 `.dark` 令牌变量对：页面/卡片 slate-950（靠边框分层）、嵌套 slate-900、正文 slate-200、次要 slate-300、边框 slate-800；语义 900/40 底 + 300 字；角标逾期底暗色用 red-600、系统示意底 slate-900、材质斜纹 slate-700。Mica 亦随既有 data-theme 浅暗切换，不另立色板。

### 移动端适配

- 捕捉窗窄屏收为近满宽底部/居中浮层，输入高度 ≥44px、正文 ≥16px（避免 iOS 聚焦缩放）；可选项胶囊换行。菜单项、跳转列表项、快速新增按钮命中区 ≥44px、相邻间隙 ≥8px。小组件在移动端对应主屏 widget（承接子任务 14），本屏小/中卡结构可复用；Widgets 板/任务栏为桌面语境，移动端以主屏小组件替代。

### 可访问性

- 纯图标/图标按钮均带 `aria-label`（复用 02/04 写法）；捕捉窗输入有可见「快速添加」标题上下文，`Esc` 关闭、`Enter` 提交多路径。
- 角标为图形元素（数字）：未完成用品牌 sky——沿用 DESIGN.md 已记录的「sky 白字 2.6:1 已知偏差」，不重复另标；逾期变体 red-700(浅)/red-600(暗) 底白字对比达标；且计数不孤用颜色，配「未完成 N / 含逾期 N」文字。
- 语义色均伴文字（逾期/今天/N 天后徽标带文字，退出破坏性带「退出」文字），信息不单靠颜色。菜单/列表 Tab 顺序与视觉一致，可交互元素聚焦显示 focus-ring。

### DESIGN.md 缺口 / 待编排者知会（未私自新增令牌）

- **无新增品牌/语义令牌**：`--os-bg`/`--os-hatch` 取自 slate-200/300（暗 900/700）既有阶，仅承担「系统层中性示意」，不进入应用组件体系、不写入 DESIGN.md 组件基准；如编排者认为「系统外观示意底」值得在 DESIGN.md 备案为设计稿约定，可加一条说明，但非新增可用令牌。
- **Mica/小组件属平台原生**：Mica 材质、Win11 Widgets/WidgetKit/AppWidget 均为原生窗口/小组件框架能力，本稿只给结构/文案/与 surface 令牌关系示意，已在稿内 amber `platform-note` 标注平台限定，复现落各原生模块，不属本母任务「按图复现」范围。
- 角标品牌 sky 白字沿用既有 2.6:1 偏差，不重复另标（同 09 处理）。
