### 构图

单栏「设计基础」海报，画板固定 1280px 宽（桌面基准），外层页面背景，内容分区为 `surface-card` 面板自上而下堆叠，区块间距 24px、面板内边距 24px（对齐 DESIGN.md 间距节奏）。分两大段：

- **令牌样例（07 组）**：01 品牌色 → 02 中性 slate 阶（含用途对照表 + 50–950 参考阶梯）→ 03 语义色三档 + 成功 → 04 字号阶梯 → 05 间距节奏 / 06 圆角与阴影（并排两栏）→ 07 图标尺寸。
- **基础组件**：按钮（default/ghost 全状态 + 待决标注）→ 输入框 / 徽标 + 卡片（并排）→ 复选框 / 开关（并排）→ 提示条 → 空状态 / 骨架（并排）→ 焦点环。

### 组件清单与状态

- 按钮：`default`（brand 底白字）与 `ghost`（slate 文字 + hover 浅底），各含默认 / 悬停 / 聚焦 / 禁用 四态；悬停用 sky-600、聚焦叠 `focus-ring`、禁用 `opacity-50` + 禁指针。
- 输入框：默认（可见 label + 值）、错误（红边框 + 字段下方错误文案说明修复方式）、聚焦（`focus-ring`）；高度 44px，`type` 语义化。
- 徽标（两族，形状不可混用）：**行内到期徽标** overdue / soon / normal 三档，6px 圆角矩形（对齐现状 `TodoItem.vue` rounded-md 与 02–06/14 功能屏）；**分类 / 状态标签 chip**（标签 / 角色 / 共享态等）胶囊 9999px（对齐 07/11/12/16 功能屏）。两族均带图标 / 文字，各配可见文字标注区分。
- 卡片：`surface-card` 样例（rounded-xl + 1px 边框 + shadow-sm，内边距 16）。
- 复选框：未选 / 选中 / 聚焦 / 禁用；附完成态（降对比 + 删除线）示例。
- 开关：关闭 / 开启 / 聚焦 / 禁用；附带文字标签行示例。
- 提示条：提示（info）/ 成功 / 错误，均图标 + 文字。
- 空状态：inbox 图标 + 主文案「还没有待办」+ 引导副文案 + 主操作按钮。
- 骨架：三行待办行占位（复选框方块 + 两行文本条 + 徽标胶囊），与真实内容同构。
- 焦点环：按钮 / 复选框 / 开关 / 通用元素四类聚焦样例。

### 状态覆盖

默认 / 悬停 / 聚焦 / 禁用（按钮、复选框、开关）；正常 / 错误（输入框）；空数据（空状态）；加载（骨架）；完成态（复选框删除线行）。

### 暗色适配（浅暗成对，镜像 DESIGN.md 暗色列）

以 CSS 变量成对：`.dark` 覆盖页面背景 slate-50→slate-950、卡片 white→slate-950（暗色卡片与页面同为 slate-950，靠 slate-800 边框区分层级）、正文 slate-900→slate-200、次要 slate-600→slate-300、边框 slate-200→slate-800；语义色按公式「浅 100/700 → 暗 900·40/300」镜像；`focus-ring` offset 由 white→slate-950；ghost 文字浅 slate-600 → 暗 slate-300。切换机制：读 `location.search` 含 `dark` 时给 `<html>` 加 `class="dark"`（镜像 DESIGN.md 的 `.dark` 类驱动）。

### 移动端适配

本稿是桌面基准海报（1280px 画板，非交互屏），移动端形态归 14 号子任务。但令牌本身已含移动约束并在稿中标注：正文基准 16px（移动端不小于 16 避免 iOS 聚焦缩放）、触控目标 ≥ 44px（输入框高 44px、间距节奏说明标注「触控 ≥ 44px、相邻间隙 ≥ 8px」）。

### 可访问性

- 正文对比：浅色 slate-900 on slate-50、暗色 slate-200 on slate-950 均 ≥ 4.5:1。
- 状态不孤用颜色：语义徽标 / 提示条 / 错误文案一律图标 + 文字伴随。
- 焦点可见：`focus-ring`（2px sky-500 环 + 2px offset）在四类元素上演示，未移除焦点样式。
- 语义标签：输入框 label 关联 `for`/`id`，错误态 `aria-invalid` + `aria-describedby` 指向错误文案。
- 图标风格统一 lucide 描边（内联 SVG，`stroke-width:2`），未用 emoji 充当图标。
