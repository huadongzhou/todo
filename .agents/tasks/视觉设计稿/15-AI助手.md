# AI助手

- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计 AI 助手相关界面。

  - [ ] 导出浅/暗 PNG 到 .agents/design/15-AI助手/

## 规格（UI/UX）

AI 助手未编码，本稿为复现参照。核心原则：**AI 只出建议、用户确认才生效**——全屏统一「AI 建议卡」语言，并明确「建议态 vs 已应用态」边界。AI 属订阅墙功能。

### 结构与布局

- 单画板 1280、48/40 padding，沿用 01/02/03 的 masthead + `section-title`（`idx` 蓝底序号 + 24/600 标题 + 灰注）分屏组织；共 8 屏：
  - 屏 01 共用语言：AI 入口标记（快速新增内联 `ai-chip`、编辑态 `ai-ghost`、侧栏 info 导航项）+ 建议卡骨架 + 建议/已应用图例。
  - 屏 02 AI 拆解子任务：输入行 + `ai-btn`，左「建议态」卡（子任务列表可编辑/逐条勾选采纳/丢弃）↔ 右「已应用态」提交列表，直观呈现边界。
  - 屏 03 智能标签/象限预填：归类组建议卡（`tag-chip.suggested` 虚线 info 框 + `quad-chip`）↔ 采纳后已应用组。
  - 屏 04 图片 OCR 转任务：`drop-zone` 上传区 + 识别源缩略 + 转任务预览建议卡。
  - 屏 05 AI 周报：数据卡三联 + 自然语言正文 + 下周建议；底栏采纳到成就/复制/丢弃。
  - 屏 06 智能我的一天 + AI 自动排程：排序建议卡（`rank` + 理由 chip）↔ 时间块时间轴（`schedule`）。
  - 屏 07 智能入箱建议：每项一条建议动作（排期/归档/拆解 `suggest-act`）+ 忽略。
  - 屏 08 状态全集：生成中（流式 + 骨架）、失败（error + 重试）、配额不足（订阅墙 + 配额条）。
- **复用组件**：`surface-card`、`alert`（info/success/error/warn）、`ctrl` 表单控件、`tag-chip`/`quad-chip`、待办完成圈、`btn-primary`/`btn-ghost`/`icon-btn`、骨架——全部逐字取自 01/02/03。
- **新增（仅设计稿内、派生自既有令牌，非新色）**：`ai-card`（`surface-card` + info 顶条 `ai-head`）、`ai-chip`/`ai-ghost`/`ai-btn`（sparkles 统一 AI 标记，info/brand 语义）、`ai-foot`「确认后生效」提示 + 采纳/编辑/丢弃、`sug-item` 建议行、`applied-*` 已应用行、`schedule` 时间块、`wall` 订阅墙、`quota-meter` 配额条。

### 状态

- **AI 入口**：内联 chip / ghost / 侧栏项三态，均带 sparkles。
- **生成中**：`ai-head` 右侧「正在生成…」动点 + 正文流式行 + 闪烁 `caret` + 骨架占位；底栏「停止生成」（动画可中断，呼应 DESIGN.md 动效基准）。
- **结果（建议态）**：info 顶条 + 建议内容 + 底栏采纳/编辑/丢弃；子任务逐条勾选（`cbx-sq`），丢弃条降透明 + 删除线可恢复。
- **已应用态**：常规提交样式（完成圈 + 普通字段块），一次性 emerald「已采纳」标记后无 info 顶条，与手动录入无差别。
- **失败**：`alert.error` + 明确原因 +「重试」，注明未消耗配额。
- **配额不足（订阅墙）**：`wall`（crown 图标 + 升级引导 + 100/100 满额红条），本地功能不受影响；另给配额充足对照（brand 进度条）。

### 暗色适配

- 全令牌浅暗成对，`?dark` 切换（与 01/02/03 同款脚本）；info(sky) 语义暗色为 `sky-900/40 底 + sky-300 字`，`--info-border` 暗色取 sky-700 与浅色 sky-300 成对；卡片暗色=页面 slate-950 靠边框区分层级；已导出 dark.png 核对，emerald/slate/sky 时间块与 error 提示条暗色均正确。

### 移动端适配

- 触控目标：`ai-btn`/`ctrl`/`sug-item` 命中区 44px，`icon-btn` 40（列表内）/44（`.hit`）；`suggest-act`/`ai-chip` ≥36 且间隙≥8。
- 窄屏：双列 `cols-2`、`ocr-grid`、`report-stats`、`schedule` 在移动端应降级为单列纵向堆叠（本稿桌面 1280 呈现两列，移动版规则在 14-移动端主要屏承接）；`ai-foot`/`inbox-suggest` 已 `flex-wrap` 防溢出。正文 ≥14/16 不触发 iOS 缩放。

### 可访问性

- AI 是建议非自动执行：每张建议卡底栏显式「AI 建议，确认后才写入」，采纳为独立主操作，不做隐式落库。
- 语义不孤用颜色：建议态除 info 色另有「AI 建议」文字 + sparkles + 虚线框；已应用态另有 emerald「已采纳」文字 + 对勾；失败带 error 图标 + 文字。
- 纯图标操作（编辑/丢弃/恢复/停止）均带具体 `aria-label`；`alert` 用 `role="status"`；建议列表勾选用方形复选语义。
- 正文对比 ≥4.5:1（沿用既有令牌）；焦点环沿用 `focus-ring`（静态稿未逐一绘制聚焦态，交互实现时补）。

### DESIGN.md 缺口（报告编排者，未私自新增令牌）

1. **AI 建议卡为全新组件语言**，DESIGN.md「组件视觉基准」无对应条目。本稿严格复用 info(sky) 语义着色、未造新色相；AI 落码时建议在 DESIGN.md 增补「AI 建议卡（info 顶条 + 采纳/编辑/丢弃 + 建议/已应用边界）」条目。
2. **AI 强调边 `--info-border`**（浅 sky-300 `#7dd3fc` / 暗 sky-700 `#0369a1`）：两值均为 DESIGN.md info-fg 在对侧模式的既有色值，非新增 hex，仅「边框」用途为新用法；如需固化为令牌由编排者裁决。
3. **AI 是否用独立品牌强调色**：本稿刻意复用 info(sky) 而非引入「AI 专属色」（如紫）。若产品要给 AI 一个区别于普通 info 的视觉身份，属新增令牌决策，未自取，留编排者裁决。
4. **订阅墙 / 配额条**（12.6 功能分层视觉）DESIGN.md 无条目；本稿用 brand CTA + info 语义 + lucide crown 呈现，落码时建议补记。
5. **既有偏差顺延**：采纳/升级等主按钮沿用 default（白字压 sky-500 ≈2.6:1）——DESIGN.md 已记的已知偏差，非本屏新引入。
