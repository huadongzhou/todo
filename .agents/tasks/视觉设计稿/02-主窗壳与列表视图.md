### 1. 结构与布局（桌面主窗，画板固定 1280px）

- **应用窗**：`surface-card`（rounded-xl + 1px 边框 + shadow-sm）内左右两栏。
- **侧栏（256px，`nested-bg` 衬底 + 右边框）**：品牌字标「Just Do」（sky-500 方形 logo）→ 主 CTA「新建任务」（brand 底白字，44px）→「清单」组（收件箱/今天(active)/计划/已完成，带计数）→「标签」组（胶囊 chip，slate `normal` 底）→「成就」→ 底部「设置」。
- **主区**：顶栏（`任务`/`视图` 双段导航 + 右侧同步状态灯 + 立即同步图标钮）→ 内容区（存储降级告警条 → 顶部快速新增条 → 五个日期分组）。
- **顶部快速新增入口**：输入框（`input-bg`=slate-100/900）+ 展开更多选项钮（SlidersHorizontal，ghost，44px）+「添加」主按钮（Plus，brand，44px）—— 与 `App.vue` 创建表单 `actions` 槽同构。
- **日期分组**：`分组标题（名 + 计数）` + 每组一张 `surface-card` 承载行，行间 `border-slate-100/800` 分隔（复刻 `TodoItem.vue` 容器）。五组：逾期 / 今天 / 明天 / 本周 / 以后。**分组顺序**把逾期置顶（最需行动），其余按时间近→远；`将来/开始日期未到` 与截止日口径的收口属 `视图与统计/01` 的逻辑议题，本视觉稿不预判分组算法，只呈现五组表面与「{日期}开始」徽标可与到期徽标共存于同一行。
- **待办行（复刻 TodoItem.vue）**：完成圈（24px，`slate-300/600` 描边；完成=`sky-500` 底 + 白勾）→ 标题（16px，`slate-700/200`；完成=`slate-400/500` + 删除线）→ 徽标行（`flex-wrap gap-2`）→ 右侧复制钮 + 删除钮（各 44×44）。
- **待办行至少覆盖的形态**（本屏全部画出）：
  1. 普通（本周组，`3 天后` = normal slate 徽标）
  2. 今天到期（今天组，`今天 · 已设提醒` = soon amber）
  3. 逾期（逾期组，`逾期 2 天 · 已设提醒` = overdue red）
  4. 已完成（今天组，完成圈勾选 + 标题降对比删除线；到期文字 `今天` 呈**无 tone 纯文本**——忠实复刻 `dueDateTone(completed)=none → TONE_LABEL_CLASS.none=""`，到期徽标无完成分支，故不带胶囊底）
  5. 带周期 + 子任务进度（明天组，`每天` 周期 pill + `连续 5 天` streak pill(emerald) + `2/3` 子任务 pill，三者与 soon 到期徽标共存）
  6. 锁定依赖（以后组，`待前置完成` 锁徽标(slate) + `7月30日开始` 开始徽标(slate)）

### 2. 状态清单

- **默认 / 悬停 / 聚焦**：按钮与输入沿用 01 组件态（default hover→sky-600、ghost hover→浅底、`focus-ring` 2px sky-500 环 + 2px offset）；标题按钮 hover=下划线 + 文字加深（`slate-950/100`），完成态 hover 只加下划线不改色（复刻 TodoItem 注释约束）。
- **空数据**：`空状态 · 列表为空` 面板——顶部快速新增条常驻 + 收件箱空态图（`slate` 次要色 opacity .7）+「还没有待办」+「在上方输入标题、按回车快速添加…」+ 快捷键提示 `Ctrl Shift Space`。复用 01 空态语言与 DESIGN.md「空状态」基准（说明文案 + 下一步引导，不留白屏）。
- **错误 / 告警**：存储降级用 01 的 `alert.error`（red 语义底 + AlertCircle 图标 + 文字）；`同步状态指示` 面板另列 success/info 两态告警作对照。
- **加载 / 同步**：顶栏状态灯四态（同步中 sky / 已同步 emerald / 同步失败 red / 尚未同步 slate），均「灯 + 文字」，颜色不孤用。

### 3. 暗色适配（浅 / 暗成对）

`?dark` 给 `<html>` 加 `.dark`，全部令牌成对切换（值同 01）：页面 slate-50→950、卡片 white→slate-950（靠边框区分层级）、正文 slate-900→200、边框 slate-200→800、输入底 slate-100→900、行分隔 slate-100→800、完成圈描边 slate-300→600、徽标三档「100/700 → 900·40/300」、streak emerald 同公式。活动导航项「今天」用 `info`(sky) 令牌对（浅 sky-100/700、暗 sky-900·40/300）—— 复刻 `App.vue` `bg-sky-100 text-sky-600` chip 并按 01 established info 对补齐其缺失的暗色分支、同时把浅色字色取 sky-700 以达 AA（非 sky-600 薄对比）。段控活动段暗色用 slate-800 抬升（卡片=页面同色）。删除钮 hover red-600→red-400 成对。

### 4. 移动端适配

- 本屏是**桌面主窗**（画板 1280px 固定）；移动端主要屏归 `移动端形态/14`（依赖 01/02/03），此处只保证令牌与组件可平滑迁移。
- 触控：待办行复制/删除钮、快速新增「添加」/展开钮、侧栏 CTA、侧栏导航项、段控 tab 均 ≥44px；相邻可点目标间隙 ≥8px（行内 `gap-2/3`）。
- 无固定宽高致溢出：输入 `w-full`、徽标 `flex-wrap`，桌面画板无横向滚动。

### 5. 可访问性

- 可访问名称：图标钮均带 `aria-label`（复制/删除/立即同步/展开更多选项/新建任务），措辞与 `TodoItem.vue` 现状一致（`复制 {title}` / `删除 {title}`）；活动导航项 `aria-current="page"`；段控 `role=tab aria-selected`。
- 信息不靠颜色单传：到期/逾期/周期/锁/streak/同步四态/告警条均「图标或文字 + 颜色」；分组「逾期」标题用 red 字色但**词本身即语义**，非颜色孤用。
- 正文对比 ≥4.5：徽标复用 01 已验证的语义色对；活动导航浅色字色取 sky-700（≥4.5，规避 App.vue 现状 sky-600 薄对比）；完成行降对比仍保留可读（slate-400/500）。
- 焦点：任何可交互元素聚焦显 `focus-ring`（本稿为静态图，焦点态语言以 01 为准，不重复铺陈）。
