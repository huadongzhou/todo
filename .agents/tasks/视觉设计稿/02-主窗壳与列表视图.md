# 主窗壳与列表视图

- 级别：简化
- 状态：设计

## 需求（产品）

- 目标与场景：设计桌面主窗口：导航壳 + 日期分组待办列表 + 待办行全形态 + 空态与同步/存储告警条。
- 范围（做 / 不做）：做 主窗导航壳（任务/视图双段 + 侧栏入口）、日期分组列表（今天/明天/本周/以后/逾期五组）、待办行全形态（完成圈/标题按钮/到期徽标三档/周期标识/streak pill/依赖锁/子任务进度 n/m/复制删除按钮）、空状态（回车快速添加引导）、存储降级告警条、同步状态指示。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：桌面端形态/01、视图与统计/01/02、任务管理列表、数据与同步（状态/告警）
- 验收标准（逐条可检查）：
  - [ ] 五组日期分组 + 待办行全部徽标形态齐备，触控区 ≥44px、删除破坏性操作 red 语义色且视觉分离
  - [ ] 空态有文案 + 下一步引导；告警条用语义色且带文字
  - [ ] 导出浅/暗 PNG 到 .agents/design/02-主窗壳与列表视图/
