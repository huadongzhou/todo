## 规格（UI/UX）

### 构图（两容器复用同一字段块）

固定画板 1280px，`?dark` 切 `.dark`；抬头与 01·02 masthead 同款。内容居中于 880px 舞台（贴近真实桌面表单宽度）。三段：

- **容器 A · 统一创建表单**（`surface-card` 24px 内边距）：首行 = 标题（label + 码点计数器）+ 展开 slider（`SlidersHorizontal`，`aria-expanded`）+ 添加（brand）；下接详情区，三组分组呈现——**内容**（备注 textarea 满宽）/ **时间**（截止日·估时两半列，重复渐进式满宽，提醒多点满宽，开始日期半列，时间段起止满宽）/ **归类**（标签色片满宽、象限满宽、清单下拉半列）。
- **容器 B · TodoItem 行内编辑态**：列表内点击标题原位展开为表单，详情区默认展开；以「时间」组为样示字段块复用（内容/归类同容器 A，从略以免重复千行），并重点呈现仅编辑态出现的**关联区**——子任务（方形复选框 + 行内改名 + 上/下移 + 删除 + 桌面 grip 拖拽）、附件（链接/文件两入口 + 打开触发 + 移除）、依赖（搜索选前置 + 结果列表 + 已选行 + 移除）——末尾保存栏（`Enter 保存 · Esc 取消` + 取消 ghost / 保存 default）。上下各一条折叠展示行（复刻 02 待办行），含**锁定态**折叠行（中性「待前置完成」徽标 + 「解锁前不提醒」title）。
- **状态板**（两列）：左 = 字段级校验错误态；右 = 三类提示条优先级。

### 字段清单（全字段展开，按 TodoFields 声明式字段表 + 契约字段）

| 分组 | 字段 | 控件（对齐实现） |
|------|------|------------------|
| 内容 | 标题（必填，含码点计数器）/ 备注 | 填充式输入 / `textarea` rows≈3，计数器近上限才现 |
| 时间 | 截止日 / 估时 / 重复 / 提醒 / 开始日期 / 时间段 | date / number（窄框）/ 渐进式频率子控件 / 多点 datetime 列表 / date / datetime 起止对 |
| 归类 | 标签 / 象限 / 清单 | 多选色片（语义色公式着色）/ 重要·紧急双 chip（复用星期 chip 视觉）+ 象限提示 / 单选下拉 |
| 关联（仅编辑态） | 子任务 / 附件 / 依赖 | 勾选·改名·排序·删除 / 链接+文件 / 搜索+锁定 |

重复渐进式：频率 select 选定后展开「每 N 单位」间隔、结束条件（永不/到某天/次数三选一 radio）；每周→重复的星期 chip；每月→月内位置（同一天/指定某日/最后一天）+ 按农历；每年→按农历；工作日/每日无附加子控件。设计稿呈每周变体 + 文字说明覆盖其余变体。归类三字段的数据底座（`tag_ids`/`important`/`urgent`/`list_id`）契约已具、UI 待接线，本稿作复现参照。

### 状态清单

- 标题：默认（有值）/ 计数器近上限（slate，`还可输入 N 字`）/ 至上限（amber）/ 空校验错误（红字 + `aria-invalid`）。
- 校验错误四例：标题空、时间段结束早于开始、估时非正整数、重复间隔越界（1–999）——均为字段下方红字 `text-red-600 / dark:text-red-400`，填充式输入不改边框（与实现一致）。
- 提醒：多点行 + 「已过」amber 提示（保存后立即提醒一次）。
- 待办行：默认 / 完成（降对比 + 删除线）/ 锁定（中性徽标）。
- 提示条（单通道 `role=status`）：error（red）/ warn（amber）/ success（emerald）三类，附优先级：先比存活 transient＜standing，再比语气 error＞warn＞success，末位比来源 form＜storage＜export＜reminder。

### 浅暗成对

令牌逐字取 01·02 `:root` / `.dark`。暗色页面/卡片 slate-950 靠 slate-800 边框分层；填充式输入 slate-100→slate-900；标签选中色 sky/emerald 语义暗色（900·40 底 / 300 字）；chip 选中 sky-500 白字不变；三类提示条暗色（red/amber/emerald 900·40 底 / 300 字）。

### 移动端适配

正文/输入 ≥16px（桌面 `sm:text-sm` 降 14）；所有输入、chip、图标按钮、上下移、删除均 ≥44×44 命中区，相邻 ≥8px；两列字段栅格窄屏折单列（`sm:grid-cols-2`）；徽标行 `flex-wrap` 折行不横滚；grip 拖拽仅桌面（`sm:` 起），排序在窄屏走上/下移按钮。

### 可访问性

分组用 `fieldset/legend`；时间段/提醒/象限/星期为嵌套 `fieldset` 或 `role=group` + `aria-label`；全字段可见 label；计数器/错误用 `aria-describedby`（不进可访问名）；错误控件 `aria-invalid`；星期/象限 chip 用 `aria-pressed`；纯图标按钮带 `aria-label` 且命中区补足；焦点 `focus-ring`（填充输入为贴边 ring-2 sky-500，无 offset，与 CONTROL_CLASS 一致）；状态信息均带文字/图标，色彩不孤用。

### 复用 01·02 说明

surface-card / alert（error·warn·success）/ badge / 待办行（`.row` 复刻 TodoItem 展示态）/ 完成圈 / 图标按钮 / ghost·brand 按钮 / 焦点环，均逐字复用 01·02 令牌与视觉语言。填充式输入、12px slate-500 label、码点计数器、星期 chip、radio/checkbox 选项行、子任务/附件/依赖行取自 TodoFields 及各子组件 CONTROL_CLASS / LABEL_CLASS，保证与实现一致（回归基线）。
