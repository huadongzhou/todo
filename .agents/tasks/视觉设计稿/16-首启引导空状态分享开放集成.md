## 规格（UI/UX）

一致性底座逐字复用 01（设计基础与组件库）、02（主窗壳与列表视图），并对齐 08（分享卡片）、10（设置面板）；令牌全部溯源 DESIGN.md，不新增令牌（缺口见末尾「DESIGN.md 缺口」）。单画板 1280px，四个分区（首启 A / 空态 B / 分享 C / 集成 D）+ 设计说明。

### 结构与布局

- **A 首启引导**（两栏）：
  - 欢迎屏：复用 10 的弹层舞台（底层应用剪影 `backdrop-app` + `scrim` 遮罩），居中 `welcome` 卡（`surface-card`）——放大版品牌标识（复刻 02 brand logo：sky-500 圆角块 + 白色勾选，hero 尺寸 64px）+「Just Do」字标 + 一句话价值标题（26/700）+ 副文案 + 单一主 CTA「新建第一个任务」（`btn-default btn-lg`，占满宽）+ 次级 ghost「载入示例任务」+ 协议同意行（首启合规，TODO 12.7）。无多步向导。
  - 首次空态：应用主区剪影（顶栏品牌 + `quick-add` 快速新增条）+ 复用 01/02 空态语言（勾选圈图标 + 「欢迎，先从一件小事开始」+ 说明）+ 示例任务 chip 行（点击即添加，对接 TODO 12.1 示例任务数据）。
- **B 全局空态汇总**：`surface-card` 面板内 4 列网格，8 个视图空态卡（列表/今日/月历/成就/搜索无结果/清单/标签/已完成），每卡 = lucide 描边图标（40 独立操作档）+ 标题（15/600）+ 说明（13）+ 下一步引导（CTA 链接/快捷键）。搜索空态额外回显查询词（`es-input` 填充式）帮助判断关键词 vs 数据问题。
- **C 分享卡片**：复用 08 `share-card`（固定深底 `#0f172a` slate-900、纯色扁平无渐变、圆角 16、340px）×3——任务卡（子任务进度条）/清单卡（完成进度 9/12）/成就卡（数字三联 + 迷你热力条，逐字对齐 08 卡面）；右侧 `share-actions`：主「导出为图片」+ 次「复制卡片」+ 卡面深浅/含进度/仅数字/尺寸（4:5、1:1）chip 组 + 本地渲染不上传说明。
- **D 开放集成设置**：`surface-card` 两栏 `integ-body`，四个 `fieldset` 分组（复用 10 legend/fieldset/表单基准）——
  - API Token 管理：空态盒（虚线框 + 生成第一个 Token）/ 首次态（一次性凭证 mono 块 + 复制 + amber 警示）/ 常态（Token 掩码列表 + 可读写/只读徽标 + 吊销）。
  - Webhook：首次态表单（回调 URL 语义输入 + 4 事件复选 `task.*` + 发送测试 + 测试成功徽标）/ 常态列表（活跃 / 连续失败态 + 测试/删除）。
  - 网页只读分享：空态盒 / 首次态（生成链接 mono + 复制 + 隐藏已完成/显示备注选项）/ 常态（已分享 + 已失效，失效/重新开启）。
  - URI 深链：协议注册状态行 + 三种深链格式（`todo://new`、`todo://task/<id>`、`todo://view/today`）mono 代码块 + 复制 + 与 9.3 卡片直达同机制说明。

### 状态

- 每分区含常态/首次态/空态，以 `state-tag` / `state-sub` + `badge-mini` 标注（常态 slate / 首次 sky / 空态 amber）。
- 按钮：`btn-default`（brand 底白字）/ `btn-ghost` / `btn-outline`；hover 以 `.hovered` 示意（ghost/图标按钮浅底、复制按钮）。
- 输入/控件：填充式 `text-input`（44px、`border-0 bg-slate-100`、语义 type：url/复选）；复选框逐字复用 01 `cbx`（brand 填充 + 白勾）；聚焦 `is-focus`（focus-ring）。
- 语义状态徽标：活跃/可读写=success emerald、只读/已失效=normal slate、只读链接=info sky、连续失败=overdue red、测试成功=success；均带图标或文字，不孤用颜色。
- 加载态：本屏为静态视觉稿，加载/骨架已在 01（骨架）与 02 建立基准，此处不重复绘制。

### 暗色适配

- 全令牌浅暗成对（`.dark` 覆盖变量，与 01/02/10 逐字一致）：页面/卡片 slate-950、边框 slate-800、正文 slate-200、次要 slate-300、输入底 slate-900；语义色暗色「900/40 底 + 300 字」。
- 分享卡固定深底 `#0f172a` 两版一致（卡面本就深色，浅暗不反色，对齐 08）。
- 遮罩暗色加深 `rgba(0,0,0,0.62)` 保证前景隔离；`?dark` 切换，已导出 dark.png 验证。

### 移动端适配

- 本稿为 1280 桌面画板（母任务范围：桌面形态；移动端主要屏归 14）。落地复现时：四分区网格降级为单列；空态 4 列→2/1 列；分享卡横排→纵向堆叠可横向滚动；集成两栏→单列。
- 触控与输入尺寸已按移动基准预留：CTA/输入/新增条 ≥44px，正文/输入字号 ≥14（正文基准 16，输入 14 与现状一致），相邻可点目标间隙 ≥8px。

### 可访问性

- 语义结构：欢迎卡 `role="dialog" aria-modal aria-labelledby`；集成分组 `fieldset` + `legend`（`aria-labelledby`）；分享卡 `role="img"` + 概述性 `aria-label`。
- 图标按钮（复制/删除/吊销）均带 `aria-label`；纯装饰剪影/热力条 `aria-hidden`。
- 状态不孤用颜色：所有徽标带文字（活跃/已失效/连续失败/测试成功…）与图标；空态含文字说明。
- 键盘：可交互元素聚焦显示 focus-ring（未移除）；深链/凭证 mono 块配复制按钮而非要求手选。
- 对比：正文 slate-900/slate-200 压各自背景 ≥4.5:1；分享卡深底白字/浅字对比达标。沿用 01 已记的 default 按钮白字压 sky-500 ≈2.6:1 既有偏差（DESIGN.md 已挂待决，本屏不新引入）。
