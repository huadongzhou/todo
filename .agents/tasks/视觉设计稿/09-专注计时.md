专注计时未编码，本稿为「先设计→后复现」的新设计参照，令牌逐字取自 DESIGN.md 与设计稿 01/02。

### 一致性底座（复用，不另造）

- 卡片一律 `surface-card`（rounded-xl + 1px 边框 + shadow-sm 唯一一档）；页面/卡片/正文/次要/边框中性色、语义色、按钮、图标、focus-ring 全部逐字取自 01/02 的令牌变量块。
- 区块用 01/03/07 同款 `section-title`（sky idx 徽标 + 24/600 标题 + 12 次要说明）分段；抬头用同款 masthead + mode-badge。
- 主按钮/ghost/icon-btn/alert/空态语言复用 01·02。图标唯一源 lucide 描边，尺寸 16 内联 / 20 按钮 / 24 独立操作。

### 结构与布局（四屏，单 1280 画板纵向排列）

1. **番茄钟主界面**：左 hero 卡（大计时环 + 状态标签 + 大数字 + 番茄周期点 + 关联任务行 + 控制区 + 本轮/今日统计 + 时长设置行）；右侧纵向堆叠 4 张紧凑状态卡（专注·已暂停 / 短休 / 长休 / 本轮完成），每张 = 小环 + 标签 + 数字 + 迷你控制。
   - 计时环：SVG stroke 环，轨道用边框中性色（slate-200 / dark slate-800），进度弧描边——专注态 brand sky-500，休息态 success emerald（emerald-700 / dark emerald-300）；round linecap，起点 12 点位。
   - 大数字：tabular-nums（防跳动）；hero 60px，紧凑 26px。**字号 >32px 超出 DESIGN.md 现有 12–32 字号阶梯 → display 档为缺口，见文末待决**。
   - 番茄周期点：4 点，已完成填 sky-500，当前描边 sky-500，未到 slate-300 / dark slate-700；伴随「本轮 2/4」文字，不单靠颜色。
   - 关联任务行：复用待办行语言（勾选圈 + 标题），前缀「正在专注」次要标签。
   - 控制区：跳过（ghost icon 44）· 暂停/开始（brand 圆形主按钮 56，白图标）· 停止（ghost icon 44，hover 转 danger red）。
2. **专注悬浮条**：置顶迷你胶囊（9999 圆角 + surface-card 边框/阴影）= 迷你环（28）+ 大数字 + 任务名（截断，max 160）+ 暂停/继续 icon-btn（32）+ 拖动/置顶把手（pin，muted）。置于浅色底衬条上示意「浮于桌面、不占主界面」。
3. **禅模式**：全屏沉浸帧，固定深色底（slate-950，不随浅暗切换——沉浸态尊重克制）；居中大环（sky）+ 72px 大数字 + 任务名 + 音景微指示；底部退出提示「Esc 或轻触退出 · 空格暂停」。仅 transform/opacity 动效意象，无装饰。
4. **专注音景**：8 张音景卡网格（无/雨声/白噪/森林/海浪/咖啡馆/篝火/风声）；选中态 = brand sky 边框 + info-bg 底 + info-fg 图标 + 均衡条 + 音量滑杆；未选=默认；「无」=静音态（volume-x）。底部主音量滑杆 + 播放策略说明。滑杆轨道中性阶、填充 sky-500、白滑块（借开关滑块质感）。

### 状态清单（默认/运行/暂停/完成/空/错误）

- 番茄钟：运行（专注中，环随剩余递减）· 暂停（环降透明 + 「已暂停」+ 继续键）· 短休/长休（emerald 环）· 本轮完成（success check + 「休息一下」引导）。
- 悬浮条：运行（暂停图标）· 暂停（play 图标 + 「已暂停」muted）。
- 音景：选中·播放中（均衡条 + 音量）· 未选·点击播放 · 无·已关闭（静音）。
- 空/初始：无关联任务时关联行降级为「未绑定任务 · 选择一个任务开始专注」引导（复用空态文案语言）。

### 暗色适配（与浅色成对）

- 全部走 `.dark` 令牌变量对：页面 slate-950、卡片 slate-950（靠边框分层）、正文 slate-200、次要 slate-300、边框 slate-800；语义 900/40 底 + 300 字；环轨道 slate-800、休息弧 emerald-300、音景滑块轨道 slate-700。
- 禅模式两版同为深色底（本身即沉浸暗态），暗版仅页面外框随之。

### 移动端适配

- hero 环最大边约束在容器内（相对单位 + max-width），窄屏单列堆叠：主界面环上、控制中、状态卡改横滑；控制按钮与 icon-btn 命中区 ≥44px，相邻间隙 ≥8px。
- 悬浮条移动端退化为顶部/底部贴边窄条；音景卡网格窄屏降为 2 列。正文/数字不小于 16（移动端）。

### 可访问性

- 计时区用 `role="timer"` + `aria-live` 语义意象；状态（专注/休息/暂停）有文字标签，不单靠环色。
- 纯图标按钮（跳过/暂停/停止/置顶/退出/音量）均带 `aria-label`，命中区补足 44px；主按钮聚焦显示 focus-ring。
- 番茄周期进度既有色点又有「2/4」文字；音景选中既有边框/底色又有「播放中」文字与均衡条，信息不孤用颜色。
- 禅模式退出提供多路径（Esc / 轻触 / 显式退出按钮），焦点可达。

### DESIGN.md 缺口（待编排者裁决，不私自新增令牌）

- **display 大数字字号档缺失**：番茄钟/禅模式的 hero 计时数字需 60px / 72px，超出 DESIGN.md「12/14/16/18/24/32」字号阶梯上限。本稿沿用既有 Inter + tabular-nums，仅尺寸超阶梯，以稿内 amber `.pending` 标注。建议：DESIGN.md「字体」节新增 display 档（如 48/60/72）供计时器等英雄数字使用；采纳后回填。字族/字重/对齐方式均未越界，仅字号一处。
- 主圆形开始/暂停键为 brand 底白图标，沿用 DESIGN.md 已记录的「default 按钮 2.6:1 已知偏差」，不重复另标。
