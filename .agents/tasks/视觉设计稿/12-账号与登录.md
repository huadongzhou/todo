账号与登录未编码，本规格为「新设计」，以 DESIGN.md 令牌为唯一事实源、复用设计稿 01（组件库）/03（表单形态）已确立的视觉。登录=邮箱+密码自建 token，离线完整可用，登录仅解锁同步。

### 结构与布局

单板 1280 画板，masthead（与 01/03 同款）+ 分区，同类元素跨屏一致。分区与构图：

1. **会话态**（两列）：未登录低压力入口卡（cloud 图标 + 「离线完整可用」标题 + 说明 + 主按钮「登录」+ ghost「注册」+ 弱链接「暂不登录，继续离线使用」）；已登录会话卡（首字母头像圈 + 邮箱 + emerald success「同步已开启」+ ghost「管理设备」「退出登录」）。
2. **登录**（居中较窄卡 ~400px，两态并排）：默认态（邮箱/密码，「记住此设备」复选框 = 设备绑定入口、「忘记密码?」链接、全宽主按钮「登录」）；错误态（顶部 red 提示条「邮箱或密码不正确」+ 密码字段 red 边框 + 字段错误）。下方另置**限流**态 amber warn 提示条「尝试过于频繁，请 60 秒后再试」示意第二种错误语气。
3. **注册 / 密码找回**（三列）：注册卡（邮箱 + 密码 + 确认密码，确认不一致 → 确认字段 red 错误，密码规则 hint）；找回步骤一（邮箱 + 「发送重置邮件」+ info 提示）；找回步骤二（验证码 + 新密码 + 规则 hint，验证码错误 red 态示意）。
4. **账号设置**（两列）：改邮箱卡（当前邮箱只读 + 新邮箱 + 当前密码验证）；改密码卡（当前密码 + 新密码 + 确认）。
5. **设备与多设备管理**（整宽列表卡）：当前设备行（平台图标 + 设备名 + 最近活跃 + sky「本机」徽标，不可移除）+ 其他设备行（+ ghost/red-hover「移除」）+ 底部「登出其他所有设备」。
6. **注销账号**（整宽 danger zone，red 边框卡、red 标题、警示文案 + red 实心破坏性按钮），与常规设置视觉分离。

复用组件：`surface-card`、masthead/mode-badge、`field`（01 有边框白底输入 + label + 错误态）、`btn-default`/`btn-ghost`、`focus-ring`、`alert`（info/success/error + amber warn）、`badge`（语义色）、复选框、icon-btn。新增仅 danger 实心红按钮（见「新增令牌」）。

### 状态

- **输入**：默认 / 聚焦（focus-ring）/ 错误（red 边框 + 字段下 red 错误文字，`aria-invalid`）/ 只读（改邮箱当前邮箱，弱化）/ 密码可见切换（eye / eye-off）。
- **登录**：默认 / 提交加载（主按钮 spinner + 禁用 opacity-50）/ 密码错误（red 提示条 + 字段）/ 限流（amber warn 提示条）。
- **注册**：默认 / 确认密码不一致（red）/ 密码不合规 hint。
- **找回**：步骤一（发送前 / 已发送 info）/ 步骤二（验证码错误 red）。
- **设备列表**：当前设备（sky「本机」，无移除）/ 其他设备（可移除，移除按钮 red hover）/ 空态（仅本机时说明文案）。
- **注销**：danger zone 常态 + red 破坏性按钮（hover 加深）。

### 暗色适配

与浅色成对，全部走 01/03 已确立的 `.dark` 令牌覆盖：页面 slate-950、卡片 slate-950 靠边框区分、正文 slate-200、次要 slate-300、边框 slate-800、输入错误边框 red-400、语义色暗色档（900/40 底 + 300 字）、danger 红按钮暗色同 hue。`?dark` 切换。

### 移动端适配

输入高度 ≥ 44px、正文/输入 16px（避免 iOS 聚焦缩放）；密码可见切换按钮命中区 44px；设备行操作按钮 ≥ 44px；居中卡在窄屏满宽单列；无横向滚动。移动屏专版归 14-移动端主要屏，本板为桌面 1280 视觉参照。

### 可访问性

- 每个输入有可见 `<label for>`；错误文字 `aria-describedby` 关联、控件 `aria-invalid`；blur/提交校验非逐键。
- 语义 type：邮箱 `type=email`、密码 `type=password`、验证码 `inputmode=numeric`，唤起正确键盘。
- 密码可见切换、移除设备、退出等图标按钮带 `aria-label`；提示条 `role=status`。
- 焦点全可见（focus-ring，禁移除）；Tab 顺序与视觉一致。
- 状态不孤靠颜色：错误/成功/限流均图标 + 文字；「本机」「同步已开启」有文字。
- 注销破坏性操作 red 语义 + 独立 danger zone + 二次确认文案，视觉与常规操作分离。

### 新增设计令牌（待编排者裁决）

- **danger 实心按钮**：底 `#dc2626`（red-600）/ hover `#b91c1c`（red-700）/ 白字，暗色底 `#dc2626` hover `#b91c1c`。取值均为 red 语义已在用色阶（03 `--danger-fg`=red-600、01/03 `--overdue-fg`=red-700），DESIGN.md「组件视觉基准·待办行」已明文「破坏性操作用 red 语义色并与常规操作在视觉上分离」，故此按钮属 red 语义在破坏性 CTA 上的应用，非平行新色；DESIGN.md 未把它沉淀为具名 Button 变体（现仅 default/ghost）。建议：采纳则在 DESIGN.md「按钮」基准补记 `destructive` 红实心变体。除此之外全部取值可追溯至 DESIGN.md / 01 / 03，无其他缺口。
