- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计系统通知样式与应用内 snooze 快捷条。
- 范围（做 / 不做）：做 系统通知（到期/逾期【逾期】标注/晨间摘要汇总/勿扰结束补推摘要）文案与形态、应用内 snooze 快捷条（刚到点待处理提醒 + 稍后/完成/跳过）。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：提醒通知
- 验收标准（逐条可检查）：
  - [ ] 通知形态区分到期/逾期/摘要；snooze 快捷条形态清晰
  - [ ] 快捷条复用待办行/按钮视觉、走单一提示区
  - [ ] 导出浅/暗 PNG 到 .agents/design/11-提醒与通知形态/

## 规格（UI/UX）

设计输入：DESIGN.md 令牌 + 已编码现状代码（`src/components/ReminderSnoozeBar.vue`、`src-tauri/src/reminder_scheduler.rs`、`crates/domain/src/summary.rs`），系统 toast 为 OS 层（Windows toast / macOS 通知中心），设计稿只示意其文案/结构/语义，不仿真 OS 外观。一致性底座逐字复用 01/02 的令牌、卡片、按钮、徽标、提示条语言。

### 结构与布局

- 画板 1280px，沿用 01/02 的 masthead + surface-card panel + section-title(idx) 骨架。两大区块：
  - **系统通知（Windows toast 示意）**：2×2 中性卡网格，四类各一张。每张 toast = 应用图标(Just Do logo，sky-500 圆角方 + 白勾) + 应用名 + 时间 + 关闭 × + 标题 + 正文；卡上方配一枚场景语义徽标（复用 01/02 badge），卡下方一行 caption 说明文案规则。
    - 到期提醒：标题=任务标题；正文=`截止日：<日期>`，无截止日为「提醒时间到了」。
    - 逾期补推：标题前置 `【逾期】`（red 语义色 + 文字，色不孤用），正文=`截止日：<日期>`。
    - 晨间摘要：标题「今日待办概览」；正文按非零计数拼接 `今日到期 N 条 · 逾期 N 条`（· 我的一天 N 条），全零不推送。
    - 勿扰结束补推：标题「勿扰时段已结束」；正文「勿扰期间有 N 条提醒待查看。」，只报计数。
  - 网格后两条 info 提示条：① 逾期重催变体（提醒通知/04：标题「逾期未完成 · <标题>」，正文「已逾期 N 天，完成后不再提醒。」），② 降级说明（桌面插件不支持动作按钮 → 稍后/完成/跳过 降级到应用内快捷条）。
  - **应用内 snooze 快捷条**：逐字复刻 `ReminderSnoozeBar.vue`——`surface-card p-4` 单条提示区。头部 = 44×44 `rounded-xl` 图标 chip（BellRing 20）+ 标题「提醒待处理」，右上 ghost 关闭按钮（44×44，X 18，`aria-label=关闭提醒快捷条`）；主体 = 任务标题(truncate, font-medium) + 副行「已到点 · N 分钟前」(text-xs tabular-nums)；操作区 = 四档时长 ghost 按钮（`min-h-11 px-3 py-1 text-xs`：5 分钟 / 1 小时 / 今晚 / 明天）+ 完成 + 跳过（ghost `min-h-11`，默认 `px-4 py-2 text-sm`）+「还有 N 项」。一次仅呈现一条，其余排队。

### 状态

- Toast：四类场景各一张（区分靠文案 + 场景徽标，非仅颜色）。
- 快捷条：① 默认态（有待处理：四档时长 + 完成/跳过 +「还有 2 项」）；② 聚焦态（完成按钮示 `focus-ring`）叠加「未启用任何快捷时长」变体（操作区以「未启用快捷时长，可在设置中开启」替代按钮）；③ 空态（无「到点且待处理」提醒时 `v-if` 不渲染整条，用虚线占位卡说明真实隐藏行为，不留常驻空卡）。
- 动作语义映射：稍后=移动到点提醒点（无新增持久化）/ 完成=`toggle` / 跳过=本会话内存搁置。

### 暗色适配

- 全部取值经 `:root` / `.dark` 成对令牌（值逐字取 DESIGN.md 与 01/02）：页面 slate-50↔slate-950、卡面 white↔slate-950、正文 slate-900↔slate-200、次要 slate-600↔slate-300、边框 slate-200↔slate-800；语义色浅「100 底/700 字」↔暗「900·40 底/300 字」。`?dark` 切换。
- 快捷条标题/任务标题用 slate-800↔slate-100，副行 slate-500↔slate-400（复刻组件 `text-slate-800 dark:text-slate-100` / `text-slate-500 dark:text-slate-400`）。

### 移动端适配

- 本屏为桌面 1280 画板；快捷条本身已是移动友好尺寸：图标 chip 44、关闭键 44×44、时长/完成/跳过均 `min-h-11`≥44px，触控目标达标；操作区 `flex-wrap` 窄屏自动换行不溢出。系统 toast 由 OS 呈现，移动端为各平台原生通知，不在本桌面稿范围。

### 可访问性

- 快捷条 `aria-labelledby` 指向「提醒待处理」标题；图标 chip `aria-hidden`；关闭按钮纯图标带 `aria-label=关闭提醒快捷条`；焦点显示 `focus-ring`（2px sky-500 + 2px offset，暗色 offset slate-950）。
- 语义不孤用颜色：`【逾期】` 为文字标注、场景徽标均带文字、副行文字化。正文对比 ≥4.5:1（沿用 01/02 已验证令牌搭配）。

### DESIGN.md 缺口（报告编排者，未私自造色）

1. **快捷条图标 chip 缺 `dark:` 变体**：`ReminderSnoozeBar.vue` 头部图标为 `bg-sky-100 text-sky-600`，未写暗色对，暗色下仍呈浅蓝 chip（#e0f2fe 底 / #0284c7 图标）。设计稿忠实复刻现状（暗色亦浅蓝），未擅自补暗色对。建议按语义公式补 `dark:bg-sky-900/40 dark:text-sky-300`（=既有 --info 暗色令牌，非新增色）—— 属现状偏差修订，交编排者裁决是否同步进 DESIGN.md 与代码。
2. **DESIGN.md「待补充」列 toast 组件未收录**：系统通知（toast）尚无组件视觉基准条目。本稿以中性卡示意（不仿真 OS），未新增令牌；toast 组件规范待编排者决定是否补记。

无新增设计令牌：所有取值均可追溯到 DESIGN.md / 01 / 02 或现状代码类名。
