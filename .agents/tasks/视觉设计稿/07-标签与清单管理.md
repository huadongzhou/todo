# 标签与清单管理

- 级别：简化
- 状态：完成

## 需求（产品）

- 目标与场景：设计标签管理/筛选与清单侧边栏及共享清单界面。
- 范围（做 / 不做）：做 标签管理（增删改色 + 标签筛选/统计）、清单侧边栏（清单列表 + 归属操作 + 单归属约束）、共享清单界面（成员/指派/权限）。；不做 产品代码改动（只写 .agents/design/<本子任务子目录>/）、不做「复现」（按图实现归对应功能模块）、不新增设计令牌（DESIGN.md 缺口停下报告编排者）。
- 覆盖模块：标签、清单
- 验收标准（逐条可检查）：
  - [ ] 标签与清单在侧栏/筛选处形态统一；共享态与个人态区分清晰
  - [ ] 空态（无标签/无清单）有引导
  - [ ] 导出浅/暗 PNG 到 .agents/design/07-标签与清单管理/

## 规格（UI/UX）

一致性底座：逐字复用 01（组件库）/ 02（主窗壳侧栏）/ 03（创建编辑的标签色片）的令牌块与组件视觉；侧栏形态衔接 02（清单/标签入口在此深化其管理界面）。画板宽 1280、`artboard` padding 40，`surface-card`（rounded-xl + 1px 边框 + shadow-sm）为唯一层级容器。

### 结构与布局（三区块，各区块 `section-title` idx 条 + 网格）

- **区块一 · 标签管理**（网格 1.5fr / 1fr）：
  - 左卡「全部标签」：头部（计数 + 主按钮「新建标签」）+ 标签行列表。标签行 = 分类色点（12px 圆）+ 名称（14/500）+ 计数胶囊（normal 语义）+ 悬停操作（筛选 / 重命名 / 删除三 `row-icon-btn`）；行间 1px `--row-divider`。其中一行呈**编辑态**（1px sky-500 描边卡）：`ctrl` 改名输入（focus 环）+ 改色调色板（5 枚 hue-500 色圆，选中态 focus-ring + 白勾）+ 取消/保存。底部「新建标签」输入行（`ctrl` + ghost 添加）。
  - 右列上「标签筛选与统计」：`info` 语义「正在筛选」活动条（带清除 ×）+ 各标签未完成占比条（bar-track / bar-fill 用分类色）。
  - 右列下「空态 · 还没有标签」：`empty` 语言（tag 图标 + 文案 + 主按钮引导）。
- **区块二 · 清单侧栏与归属**（网格 300px / 1fr）：
  - 左「侧栏」深化 02：品牌头 + 清单组（收件箱默认项 + 3 条自定义清单，色点 + 计数，一条 active 用 `info` 底）+ 新建清单**输入态**（虚线 `side-add` 行）+ 共享清单组（迷你头像叠层 / users 图标标记）。
  - 右列「归属操作 · 移动到清单」：`move-menu` 弹层，选项行为 **radio 单选**（单归属），含收件箱与三清单；「单归属约束」卡：`info` 提示（每任务仅一个清单，多维用标签）+ `warn` 提示（删清单任务移回收件箱不删）；「空态 · 还没有自定义清单」`empty`。
- **区块三 · 共享清单**（网格 1.4fr / 1fr）：
  - 左「家庭采买」共享卡：头部（分类色点 + 名 + `info`「共享 · 3 人」徽标 + 主按钮「邀请成员」）+ 成员列表（头像 + 名 + 角色徽标 + 指派计数；拥有者=success 徽标 + 静态「全部权限」，可编辑=info、可查看=normal 各带 `role-select` 下拉，待接受邀请行=虚线头像 + normal 徽标 + 撤销）+ 邀请入口行（邮箱 `ctrl` + 权限下拉 + 邀请链接 ghost）。
  - 右列「个人态 vs 共享态」对照（两 `cmp-card`，共享态卡 info 描边 + 头像叠层）+「指派 · 共享态任务行」（复刻待办行，到期徽标旁「指派给」头像徽标）内含无共享清单 `empty`。
- 页脚 `pending`（amber）标注分类调色板占位待令牌 + `foot-note`。

### 状态

- 默认 / 悬停：标签行普通态与 `is-hover`（`--opt-hover` 底）成对；`row-icon-btn`/`icon-btn`/`btn-ghost` 给出 `is-hover` 底色态。
- 聚焦：编辑输入 `ctrl.is-focus`（sky-500 环）、色圆选中 `sw.sel`（focus-ring）、radio accent-color sky。
- 选中 / 激活：清单 active（info 底）、筛选活动条、radio checked、色圆 sel。
- 空数据：无标签 / 无自定义清单 / 无共享清单三处 `empty` 引导。
- 提示态：单归属 `info`、删清单去向 `warn`；待接受邀请 normal 徽标。
- （静态视觉稿不演示加载骨架；加载态沿用 01 骨架语言，复现时接线。）

### 暗色适配（与浅色成对，`?dark` 切换）

- 令牌块 `.dark` 与 01/02/03 逐字一致：页面/卡片 slate-950、边框 slate-800、正文 slate-200、次要 slate-300；语义色转「900/40 底 + 300 字」。
- 分类色点（sky/emerald/amber/red/slate -500）两模式同 hex（色点非文字，与 02/03 一致，不反色）；头像底 slate-200→slate-800、字 slate-600→slate-300。
- 已双版截图核对：对照条 info 描边、warn/ info 提示、pending 均在暗色成对显示，无孤立硬编码。

### 移动端适配

- 触控目标：主按钮/`ctrl`/`icon-btn`/`opt-row` 高 ≥ 40–44px；`row-icon-btn` 32px 为桌面悬停密态，移动端窄屏改为常显、命中区补 padding 至 44（复现约定，稿中标注）。
- 窄屏行为：三区块网格移动端应坍缩为单列（侧栏转顶部抽屉 / 分段），色点 + 名 + 计数行结构不变；成员行头像+名+角色纵向不溢出。相邻可点目标间隙 ≥ 8px。正文 ≥ 14/16，不小于 16 的输入避免 iOS 缩放。

### 可访问性

- 纯图标按钮全部带 `aria-label`（筛选/重命名/删除/新建清单/撤销/清除筛选/邀请链接等）；调色板 `role=radiogroup` + 色圆 `role=radio aria-checked`，移动菜单用原生 radio（`name=move-list`）。
- 语义不孤用颜色：角色/状态均色 + 文字（拥有者/可编辑/可查看/待接受/共享 · 3 人）；提示条带图标 + 文字。
- 正文对比 ≥ 4.5:1（slate-900/200 正文、语义 700/300 字均达标，浅暗各验）；焦点环不移除；共享态与个人态除颜色外有徽标/头像/文案三重区分。

### DESIGN.md 缺口（待编排者裁决）

- **标签分类调色板未成令牌**：DESIGN.md 未把「标签分类色」定义为独立令牌。本稿分类色取既有语义 hue 的 **-500 档**（sky #0ea5e9 / emerald #10b981 / amber #f59e0b / red #ef4444 / slate #64748b），与 02·03 设计稿 swatch 逐字一致，未新造色系；已在页脚 `pending` 显式标注「占位待令牌」。最终调色板（档数、命名、暗色策略）归标签模块编码时确定并补入 DESIGN.md，届时本稿分类色随之替换——按角色规范，此为「新增设计令牌」候选，停下交编排者裁决，不私自写入 DESIGN.md。
