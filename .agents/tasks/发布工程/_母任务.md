- 级别：母任务
- 状态：拆解

## 需求（整体）

- 目标与场景：把产品送到用户手里并可持续运营——A 段（Windows 免费公测门槛：引导/更新/崩溃上报/中英/签名直发/协议反馈）→ B 段（Store 上架、macOS/Linux 打包、What's New/帮助、匿名统计）→ C 段（订阅分层与支付、双市场合规部署）。
- 范围（做 / 不做）：做 TODO.md 模块 12 全部功能点。不做：帮助中心之外的文档站、C 段收费开启的时点决策（多端就绪后由用户拍板）。
- 外部前置：A 段（01–07）按 W6 波次在桌面主线完成后执行（01 非代码前置可最早启动）；11 起依赖 账号与登录/01–02；非代码前置（证书/备案/开发者账号/公测部署区）见子任务 01。定价基准已定：轻订阅 ¥6–10/月。
- 整体验收标准（逐条可检查）：
  - [ ] A 段整链演练：干净 Windows 机器 下载→安装→首启同意与引导→建任务→收提醒→升级新版→反馈上报全程无阻断（公测上线门槛）。
  - [ ] 崩溃与反馈双通道可定位问题（含版本与日志）；中英双语覆盖全部用户可见文案。
  - [ ] B 段：Store 与直发双渠道版本一致性有核对机制；三平台桌面产物冒烟通过。
  - [ ] C 段：免费/订阅分层与订阅墙（同步/AI/协作/开放集成）完全一致；支付双通道沙箱全链路与退订生效；双市场合规检查单逐项有证据。
  - [ ] `cargo test --workspace`、`pnpm run check` 通过；TODO.md 模块 12 状态同步。
