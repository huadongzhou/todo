- 级别：母任务

## 需求（整体）

- 目标与场景：专注域全量落地——番茄钟状态机（绑定任务、时长可配）、专注记录入统计并与估时对比、置顶悬浮条、禅模式、专注音景。
- 范围（做 / 不做）：做 TODO.md 模块 11 全部功能点。不做：统计展示页（归成就页）、AI 排程对估时的消费（归「AI助手」）、音景收费开关（归「发布工程」功能分层）。
- 外部前置：任务管理/03（估时字段）、视图与统计/03（统计数据源）完成。
- 整体验收标准（逐条可检查）：
  - [ ] 完整番茄流程（专注→休息→再专注）计时准确（±1s/25min），最小化/锁屏不漂移。
  - [ ] 专注时长进当日统计并可与估时对比；放弃的专注按规则记录。
  - [ ] 悬浮条、禅模式、音景可任意组合互不冲突。
  - [ ] `pnpm run check`、`cargo test --workspace` 通过；TODO.md 模块 11 状态同步。
