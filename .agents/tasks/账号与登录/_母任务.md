# 账号与登录

- 级别：母任务
- 状态：拆解
- 来源方案：.agents/plan/05-账号与登录.md

## 需求（整体）

- 目标与场景：账号体系全量落地——注册/登录/登出/找回/改邮箱密码/注销（含云端抹除）、deviceId 绑定、/v1 全接口鉴权、反滥用限流；未登录离线体验零回退。
- 范围（做 / 不做）：做 TODO.md 模块 5 全部功能点。不做：同步随账号的同步侧改造（归「数据与同步」后段）、订阅状态绑定（归「发布工程」）。
- 外部前置：数据与同步/04（服务端 SQLite 持久化）完成。已锁定：邮箱 + 密码自建 token。
- 整体验收标准（逐条可检查）：
  - [ ] 账号全生命周期（注册→登录→改密/改邮箱→登出→找回→注销）在客户端内闭环走通。
  - [ ] 未登录时功能与离线体验零回退；登录后同步恢复且数据归属该账号。
  - [ ] `/v1` 全接口无凭证拒绝访问；注销后云端数据不可再取回（有验证记录）。
  - [ ] 限流对压测脚本生效、对正常操作无感；`cargo test --workspace`、`pnpm run check` 通过；TODO.md 模块 5 状态同步。
