# 任务管理

- 级别：母任务
- 状态：进行
- 来源方案：.agents/plan/01-任务管理.md

## 需求（整体）

- 目标与场景：任务域全量落地——统一创建界面一次完成全部设置；任务操作补齐（编辑、撤销重做、归档、顺延、备注、复制、附件、开始日期、依赖、估时）；周期属性（实例生成、高级/农历规则、打卡视图）；子任务体系。
- 范围（做 / 不做）：做 TODO.md 模块 1 全部功能点。不做：提醒触发（归「提醒通知」）、列表呈现（归「视图与统计」）、附件云端上行（归「数据与同步」订阅段）。
- 外部前置：数据与同步/01（端侧 SQLite）与 /03（契约扩展）完成。
- 整体验收标准（逐条可检查）：
  - [ ] 新建待办在同一创建界面内一次完成全部设置，各设置项与列表/详情往返一致。
  - [ ] 周期任务完成或到期后自动生成下一实例；高级与农历规则各有 domain 单测且 `cargo test --workspace` 通过。
  - [ ] 撤销/重做覆盖完成、删除、编辑三类操作，且撤销后两端同步数据一致。
  - [ ] 子任务完成比例实时反映在任务上；复制任务携带全部子结构。
  - [ ] TODO.md 模块 1 全部功能点状态同步为 ✅；`pnpm run check` 与手动走查通过。
