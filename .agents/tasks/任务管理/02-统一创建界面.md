- 目标与场景：新建待办在一个界面完成全部设置（README 产品定义），是所有创建路径的统一落点。
- 范围（做 / 不做）：做 标题/截止日/提醒/时间段/周期/标签/象限/清单 全部设置项的创建界面；标签/象限/清单选项数据由对应母任务提供，入口在此。不做 各维度的管理界面。
- 验收标准（逐条可检查）：
  - [ ] 一个界面内完成全部字段设置并创建成功，无需二次进入编辑。
  - [ ] 各设置项与列表/详情往返一致；非法输入有校验提示。
  - [ ] pnpm run check 与手动走查通过。
