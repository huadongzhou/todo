# 实例生成与周期标识

- 级别：简化
- 状态：设计

## 需求（产品）

- 目标与场景：带周期的任务完成或到期后自动生成下一实例（Rust 侧执行）；列表可见周期标识与下次到期。
- 范围（做 / 不做）：做 实例生成落库与标识展示；不做 提醒触发（提醒通知母任务）。
- 验收标准（逐条可检查）：
  - [ ] 完成/到期两条路径均自动生成下一实例，规则来自 06/07 引擎。
  - [ ] 列表显示周期标识与下次到期；同步后另一端一致。

### 编排者并入项（来自 06 评审第 1 轮，已裁决「转任务处理」）

**【前置必办】`Workday` 频率的 `next_occurrence` 是 O(n²)/次**（`crates/domain/src/recurrence.rs:221`）：评审 release 实测——锚点距 `after` 26 年时单次 531 ms，126 年时 12.0 s；遍历整条序列则是 O(n³)。其余四种频率的候选推进均为 O(1)。

06 完成时 `next_occurrence` 还没有生产调用方，因此不构成问题；**本子任务是第一个调用方**，接入后这会立刻变成用户可感知的卡顿。请在接入前改为从上一候选增量推进（评审给的方向），并给出改造前后的耗时对照。

补充验收标准：

- [ ] `Workday` 频率在锚点距当前若干年的场景下，单次 `next_occurrence` 与整条序列生成的耗时与其余频率处于同一量级（须给出实测数据）。
