## 需求（整体）

- 目标与场景：标签维度全量落地——标签生命周期管理（含 DESIGN.md 语义色色板）、任务多标签、按标签筛选（智能列表预置项形式）与标签维度统计。
- 范围（做 / 不做）：做 TODO.md 模块 3 全部功能点。不做：智能列表框架本体（归「视图与统计」）、统计展示页（归成就页）。
- 外部前置：数据与同步/03 完成；03 任务贴标签另需 任务管理/02（统一创建界面）完成。
- 整体验收标准（逐条可检查）：
  - [ ] 标签全生命周期（建/改/删/选色）可用；删除标签后任务不丢、仅摘标。
  - [ ] 一个任务可贴多标签，创建界面与编辑入口均可操作。
  - [ ] 按标签筛选与标签维度统计数字与列表实际一致。
  - [ ] `cargo test --workspace`（级联语义测试）、`pnpm run check` 通过；TODO.md 模块 3 状态同步。
