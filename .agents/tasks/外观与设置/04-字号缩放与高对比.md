# 字号缩放与高对比

- 级别：简化
- 状态：设计

## 需求（产品）

- 目标与场景：应用内字号档位缩放与高对比主题；一并清账 DESIGN.md 已知「按钮白字压 sky-500 不达 AA」问题。
- 范围（做 / 不做）：做 字号档位（相对单位）、高对比主题变体、reduced-motion 跟随；不做 读屏适配（未纳入）。
- 验收标准（逐条可检查）：
  - [ ] 各档位缩放无文字溢出（浅/深/高对比 × 三档抽查）。
  - [ ] 高对比模式全界面对比度达 WCAG AA，按钮遗留问题修复并在 DESIGN.md 标注（经编排者确认）。

### 编排者并入项（来自 任务管理/01 评审第 1 轮，已裁决「转任务处理」）

**`focus-ring` shortcut 全局失效**（`uno.config.ts:15-16`）：评审用本仓库 uno.config 直接跑 UnoCSS 生成器实证——`focus-ring` 只产出 `.focus-ring:focus{--un-ring-width:3px;…}`，`ring-sky-500` / `ring-offset-2` / `outline-none` **全部没有进入**，因为 UnoCSS 先按「`focus` 变体 + `ring` 工具」把这个名字匹配掉了。结果是 `Button.vue`、完成圈按钮、新增的标题编辑按钮等**每一个可聚焦元素的焦点环都不是设计意图的样子**。

修它会改动全局焦点视觉，因此不塞进任何局部功能任务，归本子任务（可访问性与高对比）统一处理。

补充验收标准：

- [ ] `focus-ring` 产出的 CSS 包含设计意图的全部声明；全仓可聚焦元素的键盘焦点环可见且对比度达标（浅暗两套都验）。

### 编排者并入项（来自 任务管理/03 评审第 1 轮，已裁决「转任务处理」）

**`uno.config.ts` 的 content 扫描范围不含 `.ts`**（表现于 `src/lib/dueDate.ts:76` 的 `TONE_LABEL_CLASS.normal`）：写在 `.ts` 文件里的 `dark:` 类名从未被 UnoCSS 生成。评审已用 `pnpm run build` 产物核实——CSS 里有 `.dark .dark\:bg-amber-900\/40` 等（来自 `.vue`），独独没有 `.dark .dark\:bg-slate-800` / `.dark\:text-slate-300`；浏览器加 `.dark` 后该徽标实测仍是浅色。既有缺陷，早于 03。

与本子任务已并入的 `focus-ring` 失效同源——都是 `uno.config.ts` 的全局配置问题，改动都影响全局视觉，请一次处理完。修 content 范围后请全仓复核：还有哪些写在 `.ts`/`.js` 里的类名此前从未生成。

补充验收标准（追加）：

- [ ] `uno.config.ts` 的扫描范围覆盖所有承载类名的文件类型；修正后全仓无「写了却没生成」的类名（须给出复核方式）。
- [ ] 到期徽标等此前受影响的元素在暗色下呈现正确。

### 编排者并入项（来自 任务管理/05 的 UI/UX 阶段，已裁决「转任务处理」）

**`Button.vue` 的 ghost 变体 `hover:bg-slate-100` 没有暗色配对**：暗色下悬停会得到一块浅色底，与 AGENTS.md CSS 规范「暗色样式以 `dark:` 变体与浅色成对提供」相违。与已并入本子任务的 `focus-ring` 失效、UnoCSS 扫描范围同属全局视觉问题，一并处理。

补充验收标准（追加）：

- [ ] `src/components/ui/` 下全部基础组件的交互态（hover/active/focus/disabled）在暗色下均有成对样式，无浅色残留。
