# 修复全局快捷键权限

- 级别：直达
- 状态：开发

## 需求（产品）

- 目标与场景：里程碑 4 已交付的「全局快捷键 ⌃⇧A 快速新增」在桌面端从未真正生效——`src-tauri/capabilities/default.json` 里声明的 `global-shortcut:default` 在该插件的 ACL 清单中是**空权限集**（`gen/schemas/acl-manifests.json` 中 `global-shortcut` 的 `default_permission.permissions` 为 `[]`），因此一项能力都没授予。主窗口每次启动稳定打出 `Failed to register global shortcut {"shortcuts":"CommandOrControl+Shift+A","error":"global-shortcut.is_registered not allowed. Permissions associated with this command: global-shortcut:allow-is-registered"}`。

  来源：`修复卡片窗口权限与同步.md` 评审第 1 轮第 4 条建议（开发实测发现、评审独立复核属实），已由编排者裁决「转任务处理」。该缺陷改动前后一致，非近期引入。

- 范围（做 / 不做）：
  - 做：按 `src/lib/shortcuts.ts` 的实际调用点补齐 global-shortcut 权限（已知调用点：`:44` `isRegistered`、`:45` `register`、`:73` `unregister`、`:83` `unregisterAll`），使快捷键注册成功、快速新增窗口能被唤起；顺带核对 `src/lib/shortcuts.ts` 的失败路径是否需要在权限修好后调整（例如原先必失败的分支是否留有死逻辑）。
  - 不做：不改快捷键的默认组合与交互；不做「快捷键设置面板」（属 外观与设置/01）；不扩大到其他插件的权限审计；不改卡片窗口权限（已在 修复卡片窗口权限与同步 中定稿）。

- 验收标准（逐条可检查）：
  - [ ] `pnpm run tauri:dev` 启动后日志不再出现 `global-shortcut.* not allowed`；快捷键注册成功。
  - [ ] 实测按下 ⌃⇧A 能唤起快速新增（若环境无法发送全局按键，需说明替代验证手段并如实标注）。
  - [ ] 新增权限逐条可解释为 `src/lib/shortcuts.ts` 的实际调用点，无冗余授权（AGENTS.md 客户端「最小权限」）。
  - [ ] 应用退出/重启时注销路径不报权限错误。
  - [ ] `cargo test --workspace`、`cargo check --workspace`、`pnpm run check` 通过。
