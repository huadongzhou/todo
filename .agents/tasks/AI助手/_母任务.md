## 需求（整体）

- 目标与场景：AI 增值线全量落地——服务端 LLM 代理与按账号配额，七项能力：拆解子任务、智能标签象限、AI 周报、智能我的一天、图片 OCR、自动排程、智能入箱建议。全能力遵守「建议 → 用户确认 → 生效」。
- 范围（做 / 不做）：做 TODO.md 模块 14 全部功能点。不做：收费开关（归「发布工程」功能分层，本母任务实现配额机制本体）、移动端拍照入口（随「移动端形态」补）。
- 外部前置：账号与登录/01–02（配额主体）完成；02 另需 任务管理/10；04 需 视图与统计/08；05 需 视图与统计/06；07 需 任务管理/03 与 视图与统计/13。
- 整体验收标准（逐条可检查）：
  - [ ] 七项能力全部「建议→确认→生效」，无任何静默数据变更；离线时入口降级且主流程无损。
  - [ ] API key 仅存服务端；配额计量准确（并发不重复扣/漏扣），超额提示友好。
  - [ ] 每项能力用真实数据走查一次并留样例记录（拆解质量、预填命中、周报事实性、排程合理性）。
  - [ ] `cargo test --workspace`（代理与配额）、`pnpm run check` 通过；TODO.md 模块 14 状态同步。
