## 需求（整体）

- 目标与场景：开放能力全量落地——todo:// URI 深链（协议注册/快添/定位）、API Token 管理与 REST API、Webhook、邮件转任务（专属转发地址）、网页只读分享（拉新入口）。
- 范围（做 / 不做）：做 TODO.md 模块 15 全部功能点。不做：订阅开关（归「发布工程」）、深链移动端注册（随「移动端形态」）。
- 外部前置：01 无外部依赖可提前执行；02 起需 账号与登录/01–02；05、06 需 数据与同步/04 完成。
- 整体验收标准（逐条可检查）：
  - [ ] 深链被浏览器/跳转列表/小组件三类来源唤起均正确路由（冷/热启动）。
  - [ ] 第三方仅凭 API Token 可完成任务读写与变更订阅，无 Token/越权/超频均被拒；有最小对接示例脚本。
  - [ ] 邮件转任务与网页分享双向可用；分享链接失效后立即不可访问。
  - [ ] `cargo test --workspace`（鉴权/签名/失效逻辑）、`pnpm run check` 通过；TODO.md 模块 15 状态同步。
