# 常用提示词

## 多 Agent 流程

AGENTS.md「多 Agent 流程」节已约定：产生代码或文档改动的任务默认自动进入流程，因此直接描述任务即可触发，无需特殊措辞：

> 新增番茄专注计时功能

### 控制词

写在任务描述中即可覆盖默认判定：

| 措辞                                 | 作用                                                                                                                                                         |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 直接改                               | 跳过流程，直接实现                                                                                                                                           |
| 走全流程 / 走简化 / 走直达           | 强制指定任务级别，不由编排者判定                                                                                                                             |
| 继续 <任务名>                        | 读 `.agents/tasks/` 下对应任务文件的状态行（单任务 `<任务名>.md`、子任务 `<母任务名>/<序号>-<短名>.md`、母任务 `<母任务名>/_母任务.md`），从当前状态继续推进 |
| 只出需求 / 出完规格暂停 / 评审完暂停 | 推进到指定阶段后暂停，等待人工确认再继续                                                                                                                     |
| 拆解 <大任务>                        | 升格为母任务：建 `.agents/tasks/<母任务名>/`，产出拆解清单后停下等确认                                                                                       |
| 拆完直接跑                           | 跳过拆解确认门，直接开始执行子任务                                                                                                                           |

### 手动完整触发

用于 AGENTS.md 未被自动读入的会话或其他 AI 工具：

> 按 .agents/workflow.md 多 Agent 流程执行以下任务，你担任编排者，从定级与创建任务文件开始：<任务描述>

### 单独调用某个角色

不走完整流程、只要某一阶段产物时，按 `.agents/workflow.md`「派发调用模板」填写，例如只要评审：

> 你现在担任「评审」。完整阅读 .agents/roles/reviewer.md 与任务文件 .agents/tasks/<任务名>.md，按其工作步骤执行。
